## 3. 口径与边界

- **P2 只做多根记忆/审计/锁**：guard/header/提前压/保护/回注仍是 P1 主根行为（**未碰 P3**）。
- `configRoot` 强制合并：其下会话单一 root/store，嵌套 `.git` 不另立根；已知限制「显式配置根内多根隔离不完整」保留。
- `mem_write` 只写本会话根，无 root 参数；`mem_query` 接 `exec`、只查本会话根；跨根 text 不回退；ID 同号只命中本根同号、不返回别根内容（P3/P4 聚合用 `rootId + id`）。
- `logFile` 两处白名单 + 实际写入 containment 保持 P1 v3；旧根 logs 路径拒绝；本机已迁移用户级。
- 多进程同根不合并：第二进程只读/锁提示，`mem_write` `[READ_ONLY]`、查询可用；第一笔写入完整，锁释放后可写。
- **P2 不可安装/不可发布**：其他根记忆可写，但其压缩/保护/回注/header/提前压仍缺（P3）；P2 完成 ≠ 功能闭环。
