## 1. 发布阻断：回放 fixture 脱敏不完整

**根因**：旧 `extract-replay-fixture.mjs` 用 `REDACT_KEYS` 按 key 白名单脱敏，漏了 `args`/`texts`/`sessionId`；
短片段数组（`data.stream[].args[]`/`texts[]`）单串检查绕过后，按序 join 可还原正文/路径/工具参数；T7-R2 只查 `key=text` 与连续子串。

**修法（已落地）**：

1. `sanitizeDeep()` 改为**递归所有字符串**，不再依赖 key：
   - 含 CJK / Windows 盘符或 UNC 绝对路径 / POSIX 常见根路径 / URL / 长 token（≥64 的 base64/hex 片段）→ 整串 `[redacted:<长度>]`；
   - 其余字符串中的 `session-<uuid>` → `[session-id]`，裸 uuid → `[uuid]`；
   - **字符串数组**先按序 join 判断：join 后含敏感模式 → 整组替换；≥20 个、平均长度 ≤6 的短片段流（token/stream）也整组替换；
   - 数字/布尔/结构不变。
2. 重生成两份 fixture（自动 18:41、手动 00 会话）；生成前对整份 fixture 再跑一遍 `sanitizeDeep`。
3. 新增独立扫描器 `analysis/t7/scan-fixture.mjs`：递归字符串 + **join（带/不带分隔符）** + raw 文件三层检查，供人和测试共用。
4. T7-R2 改为硬断言（不再查 key）：递归所有字符串禁 CJK/绝对路径/URL/session-uuid/裸 uuid/长 token；join 与 join-tight 同查；raw 不得出现 `session-53ece2c2`/`19091`/`DS-PROJECT`/`AGENTS.md`。

**重生成结果**（scan 输出）：

```

replay-compaction-manual.json: strings=1851  violations=0
```

- raw 文件 CJK=0、`19091`=false、`session-53ece2c2`=false、`DS-PROJECT`=false；
- 回放功能未破坏：`test/t7-replay.test.mjs` + `test/t7-scenarios.test.mjs` → **15/15 通过**（自动+手动周期回放、S4-M 手动审计、回注仍发生）。
