## 亮点

- **提前压默认开**：`turn/end` 后按压力窗口（默认 60.0%–67.34%，近 native 让给宿主）调用宿主 `compactNow`；压缩**不可逆**，原文只剩摘要与记忆指针。
- **可退三通道**：会话 `/cg compact disarm`、全局配置 `compact.early.armed=false`、profile `compact.early=false`；三层关闭均有「0 触发」证据（`analysis/req-20261025-09/0.2.4-T4-回退演练.md`）。
- **可观测**：`/cg status` 的 `early=`（含来源）与 `last-early:`（原因/effective/时间）；审计 `early-armed/disarmed`、`early-forced/skipped/aborted/failed`；真实触发另写 `compaction-cost`。
- **安全边界**：项目层 `.cg-policy.json` 不能开关 armed（忽略 + `policy-invalid(project-excluded)`，不清空整层）；不做环境变量开关。
- **失败口径**：busy → `early-aborted`（不写成 failed）；真失败 → `early-failed` 不重试；`protection=failed` 只记录、不关闸。
