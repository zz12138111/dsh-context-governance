## 2. 变更清单

1. **真会话级**：`/cg set`、`/cg compact arm|disarm`、`/cg profile` 按 `sessionId` 分桶；A 会话的覆盖不影响 B；重启清空会话层、回默认。审计 `early-armed/disarmed` 同时带全 `sessionId` 与 `sessionShortId`（B-4）。
2. **`/cg profile` 新入口**：按会话打标（`batch` / `coding` / `review` / `research`）；`/cg status` 显示 `profile: … (source=session|config|default)`。
3. **单根模型（R-MEMROOT / #11）**：根来源优先级 **显式配置 > 持久化状态 > 首次推断**；未配置时首次按会话 cwd 上溯最近 `.git` 目录，`realpath` + 盘符归一后持久化；重启沿用、不重推、不跟随 cwd 漂移。
4. **作用域（B-1 / #1）**：根外会话一律外部：`early-skipped(foreign-session)`，不提前压、不回注、不读写其记忆，只记录事实与用量；根无法确定时 `no-project-root`；策略总闸关闭时 `out-of-scope`。三枚举互斥。
5. **窗口与状态如实（#4/#5）**：`at ≥ native−0.02`（含边界）拒绝；窗口收缩使生效层落入该区间时自动失效并记 `window-shrunk`，`/cg status` 不得显示 `early=on`；观测未校准时显示 `unvalidated`，不裸 `on`。
6. **审计（#2/#10）**：无 fresh report 时 `compaction` 写 `unknown`，不写 `committed`；保护失败统一写 **`compaction-loss`**（带 `manual:boolean`、`trigger:'auto'|'manual'`），旧 `manual-compaction-loss` 仅保留读取别名、不再新写。
7. **安装契约（#8）**：包内 0 绝对路径；`projectRoot` / `project` / `logFile` 默认空；`logFile` 非空必须绝对、相对 `CONFIG` 拒绝；空 `logFile` 不建文件、不报错、不写 cwd；D9=A 首次推断根并持久化；`project` 由根 basename 补；隔离 profile 装/卸/回滚演练通过。
8. **工程面**：`test/` 不再进发布包；`install-8` 单测扫描 `npm pack` 清单；全量 419/419。

## 4. 提前压（默认开启）

当会话上下文压力达到或超过 `compact.at`（默认 **0.60**，真实占窗口比例）且低于宿主 `native−0.02` 时，插件会在 `turn/end` 后 50ms 检查并调用宿主 `compactNow`，触发一次**真实压缩**。
**压缩不可逆，会丢弃会话原文，只保留记忆指针与最后一条用户消息；重要内容请先记入记忆。**

关闭通道：
1. 当前会话：`/cg compact disarm`（会话级、立即生效；`/cg compact arm` 恢复）；
2. 全局：配置 `compact.early.armed: false`（加载后生效）；
3. profile：`compact.early: false`（`research` 已预置）。

**项目层 `.cg-policy.json` 对该开关不生效**（既不能开也不能关；出现即忽略并记 `policy-invalid(project-excluded)`）。**不存在环境变量开关。**

关闭提前压**不会阻止宿主原生压缩**；宿主 native 阈值附近的压缩仍可能发生。

## 5. 项目边界（决定谁会被治理）

插件只治理**一个项目**。根来源优先级：**显式配置 > 持久化状态 > 首次推断**。

- 配置里写了 `projectRoot` 就以它为准；**没写时**，首次需要按当时会话 cwd 上溯最近含 `.git` 的目录，作为项目根并**持久化**；**重启沿用、不重新推断**，不随会话/cwd 漂移。
- 根外的会话一律按**外部会话**处理：不提前压、不回注、不读写它的记忆，只记录事实与用量。该“不读写记忆”承诺**仅限压缩观测、保护、回注与成本记录**；`mem_write` / `mem_query` 的限制见 §6。
- 根变化（配置变更 / 持久化丢失 / 换机）在 `/cg status` 与审计中可见（`project-root-changed` / `inferred-fresh`）；**已写记忆不迁移、不删除**。
- `/cg status` 的 `only-project=on/off` **仅为展示**，不改变作用域；`onlyProject=false` 也不会扩大作用域。作用域始终由项目根决定，根外会话一律外部。`cwd===''` 的 `unattributed` 属内部放行行为，不构成 Release 承诺。
- 换项目请修改配置；不做多项目自动纳管（1.0 单根模型）。

## 6. 已知限制

### 6.1 记忆工具未按会话隔离（§4.8b，1.0 不修，计划 1.1）

`mem_write` / `mem_query` 未按会话/项目根校验；**外部工作区的会话也可能读取或写入本项目记忆**。本插件的“外部会话不读写记忆”承诺**仅适用于压缩观测、保护、回注与成本记录**，不包含这两个记忆工具。需要严格隔离时，请只在项目内会话使用；1.1 将补同一作用域判定（外部/未知会话拒绝并审计 `memory-tool-rejected`）。

### 6.2 记忆自动去重未实现（§4.8，计划 1.1）

重复写入不会自动用新条目取代旧条目；同类 `active` 条目超过 header 配额时，旧条目内容也会被注入；`/cg status` 的 `active` 计数可能偏高。可用 `mem_write` 的 `supersede` / `expire` 显式处理。

### 6.3 其他边界

- 不提供**动作校验**（pre-execute 拦截）；不提供**折叠 / 账本**（后置 1.1）。
- `engines.dsh` 只承诺 `>=0.2.1-rc.2 <0.2.2-0`；**0.2.2+ 未验且会被拒载**。
- `/cg status` 的 `adapter=` 是插件侧推断，**不等于实际后端**；后端以 profile redirect + bundle 为准。
- 审计中 `trigger=manual` 不等于“用户手动压缩”：插件提前压走宿主 manual API 路径（`sourceCommandId='early-auto'`），宿主会按 manual 记录。

## 8. 破坏性变更

1. **真会话级**：`/cg set`、`/cg compact`、`/cg profile` 从进程共享改为按会话；A 的覆盖不影响 B；重启清空会话层。依赖“全局一改全生效”的用法需改为逐会话设置或配置层。
2. **根模型改为 `profileContext` 身份 + 用户级状态文件**：状态文件为 `context-governance/root-state-<profile>.json`；根默认空、首次推断并持久化；不再以环境变量作身份来源；不做多项目自动纳管。已有显式 `projectRoot` 配置优先。**旧配置若依赖“未配置回落 process.cwd”，行为改变**。
3. **`/cg profile` 为新命令**：profile 只影响当前会话；`research` 关闭提前压；`coding` 无 preset 覆盖（沿用默认 `at=0.60`）；`/cg set profile=...` 按未知键拒绝。
4. **`logFile` 相对路径不再被接受**：非空相对路径直接 `CONFIG` 拒绝（旧行为会 `path.resolve` 到进程 cwd）。
5. **`at` 上界更严格**：从旧口径的 `> native` 收紧为 `at ≥ native−0.02`（含边界）拒绝；窗口收缩会使生效层失效并显示 `early=off (...)`，不再静默 `on`。
6. **审计事件名**：新写统一 `compaction-loss`（`loss-v1.0`）；`manual-compaction-loss` 仅作历史读取别名；`compaction-cost` 仍为 `cost-v1.4`。
7. **`/cg status` 行变化**：新增 `project-root:`、`persistence-identity:`、`last-loss:`；`scope:` 的 `only-project` 仅展示；`early=` 在未校准/非可用区间可能显示 off。
8. **发布包不再包含 `test/`**：运行时不受影响，但基于包内测试文件的脚本需改用仓库测试。
