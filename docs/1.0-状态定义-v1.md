### 1.1 提前压开关（⚠️ 待用户确认 —— 本文件最关键的一节）

**🔍 现状（2026-10-26 02:41 现采）**：`src/index.js:527` 传 `getArmed: () => false`，写死；`early-wiring.js` 在 `armed=false` 时**不审计、不取 agent/engine、不调用**；`early.js` 的 `arm()/disarm()` 无人调用；全仓无配置项或命令能打开它。所以「提前压」能力已通（判定十道闸 + `turn/end` 接线 + `early-*` 审计都复核通过），但**永远不会真实触发**。

**建议：1.0 默认关（`armed=false`）**，理由四条：

1. **无真实触发样本**：G2/G3 验的是「读数是否即时、busy 是否映射成 `busy` 而非 `failed`」，全程 `armed=false`；仓库里**没有任何一次真实提前压成功/失败的真机记录**。
2. **不可逆**：真实压缩会丢会话原文（只剩记忆指针 + 最后一句）。首日全量默认开，一旦有 bug，影响所有会话且无法还原。
3. **与 header 默认开的性质不同**：header 只**增**一段注入、不改会话内容，风险面小，所以可以默认开；提前压**改变会话历史**，不该用同一个默认。
4. **与既定原则一致**：「失败显式、可回退、不静默降级」（M2 草案 §3）；默认关 = 用户知情后才动。

**开启方式（建议，最终命名由开发定，但语义边界需求侧锁死）**：

| 通道 | 建议形态 | 约束 |
|---|---|---|
| 配置 | `compact.early.armed`（boolean，默认 `false`） | **只允许插件配置层 + 会话命令**；**项目层 `.cg-policy.json` 禁止设置**（不可信输入——恶意仓库不能替你打开真实压缩） |
| 命令 | `/cg compact arm` / `/cg compact disarm`（会话级） | 会话结束自动失效；`/cg status` 必须显示 `early=on (session)` / `off (default)` / `off (policy:…)` |
| 确认 | 首次开启需显式二次确认（如 `--yes`） | 因为不可回滚；文案须写明"会真实压缩本会话，原文丢失，只有记忆指针" |
| 审计 | `early-armed` / `early-disarmed`（含来源层、会话短 id） | 与 `early-forced` / `early-aborted` 同一族 |
| 不做 | 环境变量开关 | 不可审计、易误配 |

**备选：1.0 默认开（`armed=true`）** —— 代价：首日全量真实触发、无样本；若走这条，需求侧要求至少先做 ① 隔离 profile 上真实触发 1 次（记录 `early-forced` + `compaction-cost`）② 用户会话首压前有明确提示，不能静默。**这条需要用户明确拍板。**
