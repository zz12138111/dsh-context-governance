# 适用范围与已知限制（用户可读）

> 本文用非判据语言说明：哪些会话会被治理、降级时你会看到什么、当前 RC 有哪些已知限制。

## 1. 哪些会话会被管（1.1.0 终版口径；当前 RC 见 §3）

- **有 session id 的会话都会纳入治理**：压缩策略、保护/回注、审计与成本账本。**（当前 RC 尚未实现 C36：无 `.git` 工作区暂不纳入，见 §3；本条为终版口径）**
- **每个会话的压缩比独立保存**，重启 DSH 后各自保留；工作区是否有 `.git` **不影响**是否受治。
- 工作区/根只决定记忆与审计挂在哪个目录、以及项目级默认值；拿不到可用工作目录时**仍然受治**，只是记忆不落到项目里，并留审计。
- 没有 root 时，你的**每会话压缩比仍会保存并在重启后保留**（按 session id 记，不依赖工作区）。

## 2. 降级时你会看到什么

1. **无 session id**：不治理（正常情况不会出现），审计 `no-session-id`。
2. **工作目录不可读/不可写/离线**：压缩与审计照常；记忆/项目分组不可用，审计 `root-unresolved`；**压缩比仍保存、重启保留**。
3. **显式关闭**（`out-of-scope`，用户/配置选择）：不干预，但留审计。
4. **observe-only**（宿主能力缺失）：**仍纳入**，只观察、不主动干预；压缩事实与成本仍记账。

## 3. 当前 RC 已知限制

- **`rollback-point`**：存在 b 类损失与指针回补路径（已记录，非本轮新增）。
- **early 通道**：`early-auto` 在真机尚未触发验证。
- **陈旧锁自愈**：尚未真机触发验证。
- **平台级会话覆盖（C36）尚未实现**：无 `.git` 的工作区目前仍不纳入治理，将在 1.1.0 终版补齐。
