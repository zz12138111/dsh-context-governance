**修法**：

  - `type/seq/time`；`data.compactionId/sourceCommandId` → `[id]`；`shadowedSeqs`（整数数组）、`shadowedRange`（start/end）、`shadowedTokenCount`、`usage`（仅五个 token 数值）、`provider/model/role/kind/form/plugin` 等枚举；`source.kind/form/plugin`、`message.role/source.kind` 等 id 引用；

- 重生成两份 fixture：大小降到 **58 KB / 55 KB**（原 571 KB / 475 KB）。

## 2. P3-1：commands 晚挂载竞态

**问题**：`commands` 移出 inject 后，若 commands 晚于治理插件挂载，`/cg status` 首次注册失败只有 warn，之后不会重试。

**修法**（`src/index.js`）：首次失败仍 warn（含原因），并：

- 优先 `ctx.inject(['commands'], retry)`：服务出现时自动重试一次；
- 没有 `ctx.inject` 时 `setTimeout(retry, 0)` 下个 tick 重试一次；
- 重试成功写 info，dispose 时释放最终注册的 handler（`commandRef.current`）。

**测试**（`test/t7-p2.test.mjs`）：commands 初始不存在 → apply 成功且 warn；随后注入服务并触发 `ctx.inject` 回调 → `cg` 命令注册成功（晚挂载可恢复）。

## 3. P3-2：`reinjection-shadowed` 用 `shadowedRange` 兜底

**问题**：回注被吞判定只看 `shadowedSeqs`，缺该数组时漏判。

**修法**（`src/compress/runtime.js`）：命中条件改为 `shadowedSeqs.includes(seq) || (seq >= shadowedRange.start && seq <= shadowedRange.end)`；`tokensDropped` 同步按兜底结果累加。

**测试**（`test/t8-cost.test.mjs`）：第二次压缩清空 `shadowedSeqs`、只给覆盖回注 seq 的 `shadowedRange` → 仍写 `reinjection-shadowed`。
