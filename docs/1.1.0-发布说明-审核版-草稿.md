## 2. 相对 1.0.3 的主要变化（按面）

### 2.1 会话层写入（新）

- **`/context-governance/session-policy` 写入口**：UI 保存「本会话压缩比」与「恢复全局」从只读快照变为可写，返回 `{at, source, via}`。
- **三层优先级**：A1（运行时/命令面）> **A2（会话持久层）** > 项目模板 > plugin 层。
- **A2 落盘**：`<DSH home>/context-governance/session-policy.json`，键 = 完整 session id，值 `{at, source:'session:A2', updatedAt, version:1}`；**重启读回**；上限 `maxEntries 500` + `ttlDays 90`，淘汰记 `a2-evicted`。
- **清除会话自定义**（C27/C29）：`reset` 清 A1+A2 并回落 plugin 值，成功记 `policy-set{key:'*', value:'reset'}`。
- **审计归属**：`policy-set` 按**会话根**落 `audit.jsonl`（此前一律落主根，导致 G 根会话的写记到 D 根）。

### 2.2 写入安全（C31，新）

- 只放行 loopback（`remoteAddress` 强制）+ 三证**任一**：合法 `Origin`、`Sec-Fetch-Site: same-origin`、宿主 token/nonce。
- 拒绝原因**三分不合并**：`missing-proof` / `cross-origin` / `not-loopback`。
- 成功审计记 `via: origin|sec-fetch|token`（**只记类型，不落 token 值**）。
- 附加约束：只允许 `POST`、白名单键、请求体 ≤4KB、`no-store`。

### 2.3 多根记忆（C36–C39，新）

- **多根模型**：每会话按自身 `cwd` 归一为记忆/审计归属，`root = realpath(cwd)`；`projectRoot` 非空时其下会话归 `projectRoot`（`source=config`）。
- **记忆按会话隔离**：指针索引存 `<home>/context-governance/sessions/<sessionId>/`，条目 `MEM-<sessionShort8>-YYYYMMDD-NNNN` → `路径:行号` + 摘要；正文权威在人工文件，插件**只存指针、不读写正文**；默认不跨会话共享，`promote` 走 `shared/<rootId>/` + `memory-promoted` 审计。
- **无根/不可用 cwd 不静默**：写 `root-unresolved{sessionId,cwd,reason}` 审计（每会话每 cycle ≥1、同 cycle 去重），压缩与审计照常。
- **根删后不重建**（P4）：根目录被移走时不静默重建目录，状态显示 `(root-unresolved)`。
- **路径基座统一**：用户级文件统一到 `<DSH home>/context-governance/`（此前会话记忆在 `~/context-governance/`、A2/plugin-policy 在 `~/.dsh/context-governance/`，两处基座不一致）；旧位置可识别、不自动迁移。
- **外发可移植性**（C39）：包内无本机会话 id、无 `C:\Users\` 路径、无凭据形态（离线门 44 PASS / 1 SKIP）。

### 2.4 UI（C40 + B1/B2）

- **chip 弹层几何**：导出 `computePopoverRect`——默认**向上**；仅上方空间 < 面板高+16 才翻下；宽 `≤ min(360, 视口−16)`、高 `≤260`；水平中心对齐 chip（偏差 ≤8）后整体贴边平移、**不做左右翻转**；四边 ≥8；上弹底边 ≤ 输入框顶−4、下弹顶边 ≥ 输入框底+4（与输入框交集恒为 0）；定位前 `visibility:hidden`。
- **主视图精简 ≤3 行、每行 ≤18 汉字**：数值 / 状态 / 生效。保存 → `本会话·已保存（重启保留）` + `重启后从已保存值读回`；reset → `已清除本会话覆盖` + `重启后仍生效`。**禁** `source=`、`session:A*`、「本次修改写入」，**禁**「重启失效」与「重启保留」并列。
- **细节下沉**：原四行技术信息改由「详情」折叠（默认收起），设置页仍用详情口径。
- **关闭与焦点**：Esc / 点外部 / 再点 chip 关闭后**焦点回 chip**；切会话自动关。
- **reset 后即时刷新**：重取快照并写回（输入框、来源层、生命周期三件同 tick 更新），不再留旧值。

### 2.5 设置页与持久化

- settings 读写走 `settings-policy` 解析，plugin 层持久值 `~/.dsh/context-governance/plugin-policy.json`（幂等落盘、版本容错、损坏记 `plugin-policy-load-failed` 并回落）。
- `mountPluginPolicyRoute` 传 `csrfToken`（rc.11 首包曾漏传导致 UI 写被拒，已修并加门）。

## 3. 兼容与升级

- **从 1.0.3 升级**：直接替换安装目录即可；`engines.dsh` 双区间使 0.2.1-rc.3 与 0.2.2-rc.3 均可载入。
- **配置键**：`compact.at` 默认 **0.60**；`compact.early`/`early.armed` 默认 `true`；`cooldownMin 10`；`minDeltaTokens 20000`；`estimateSafety 1.35`。项目层 `.cg-policy.json` 不生效于 `compact.early.armed`（记 `policy-invalid(project-excluded)`）。
- **数据位置**：A2 与 plugin 持久值在 `<DSH home>/context-governance/`；会话记忆指针在 `sessions/<sessionId>/`；审计在各根 `<root>/memory/governance/audit.jsonl`。
- **回滚**：卸载/回滚**不迁移、不删除**已写记忆；回滚不回写旧根。

## 4. 已知边界（必须随 Release 披露）

1. 无 pin / 无 cwd 会话经 UI 保存时，`policy-set` 落主根审计；该路径**尚未**发 `root-unresolved{sessionId,cwd,reason}` 事件（`src/index.js:971` 直接回落 `primaryAudit`）。A2 值按 session id 落盘、不受影响；下版补。
2. `policy show` 的 `layers:` 不含运行时 A2，且 A1 标签写 `session`。
3. `user-store:` 分隔符混用（诊断文本层面）。
4. `compaction-loss{rollback-point,b-class}` 历史遗留假告警不删除；`8097e0a` 起改判 pass + `protection-covered`。
5. 显式配置根内多根隔离不完整（`projectRoot` 内不再按 `.git` 细分根，P1/P4 已披露）。
6. 宿主 cwd 校验先终止的任务形态（CP5）本机不可造，靠离线等价覆盖。
7. 第二 `DSH_HOME` 场景未做真机覆盖。
8. token 由快照下发；真实边界是 loopback，勿在非 loopback 暴露监听。
9. `compliance-scan.mjs` 按 git 跟踪文件扫；对解包目录运行会假绿。
