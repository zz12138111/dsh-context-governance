## 10. 偏差与未闭环（不得隐藏）

1. **configRoot `primaryRoot`**：计划 §5.2 写“primaryRoot=outer”，但 P1 设计 `§2.2` 与测试 `root-state-2a.test.mjs:578` 明确“config 不得改写持久化主根（移除配置后要回落到它）”；实测 `primaryRoot=null`、`configRoot=outer`、挂载根为 outer（`source=config`）。这是**计划判据与 P1 冻结口径冲突**，不是插件写错；发布前需决定改计划判据还是改设计，不能把 null 写成 outer。
2. **desktop 进程 ID**：配置字段稳定，进程 ID 因宿主子进程重启变化；不声称“全部字段一致”。
3. **migrate profile-after**：收尾时补采，非卸载当时证据；关键字段一致，但时效性标注。
4. **测试抖动**：正式三连通过前有两次瞬时失败（时序 / Windows 清理），未修改测试；不声称“零抖动”。
5. **`/compact` 保护校验**：四件套已触发，但 `compaction-loss` 失败项存在；不写成“保护全过”。
