## 1. 验收 checklist（10 条 + 需求新增第 11 条，条件纳入）

### 1. B-1 跨项目：压缩动作跨出边界、保护/账本不跨

- **验什么（单根模型；根来源优先级：显式配置 > 持久化状态 > 首次推断）**：
  - 根**已确定**（配置或已持久化）且会话 cwd 不在根下 → 外部会话，`early-skipped(reason=foreign-session)`；
  - 根**无法确定**（未配置且首次推断失败，cwd 无 `.git` 祖先）→ `early-skipped(reason=no-project-root)`；
  - 策略层禁用（总闸 `compact.early=false` / 项目层）→ `early-skipped(reason=out-of-scope)`（与位置无关）；
  - 外部会话的宿主原生压缩只记**事实与用量**；本项目（根下）会话四件套齐。
- **怎么验**：配置根 → 双仓（根内会话 + 另一 git 仓会话）；未配置 → 先开 git 仓会话让根推断并持久化，**重启**后再开第二个 git 仓会话 + 一个无 `.git` 目录会话；另跑总闸关闭用例；审计 `grep -n 'early-skipped\|early-forced'`；`compactNow` spy 计数；status 看根/来源/枚举。
- **通过判据**：
  - 外部会话：`compactNow=0`、无 `early-forced`、`foreign-session`；宿主原生压只写 cost/usage（无 protection/reinjection、不读写外部记忆——**此承诺仅限压缩观测/成本记录，不含 `mem_write`/`mem_query` 工具，见 review §4.8b**）；
  - 本项目会话：`protection-write → materialized → reinjection → compaction-cost` 四件套齐；
  - 三枚举**互斥**：`foreign-session`（根已确定但不在根下）/ `no-project-root`（根无法确定）/ `out-of-scope`（总闸或项目层），同一会话不同时出现两个；
  - 无根会话无 memory 写入；双会话不串写；status 可见「根 / 来源（配置|推断）/ 枚举」。
- **证据**：`analysis/req-20261025-12/1.0-10条-复验/01-B1/`（audit 摘录、status、测试名、双会话 id、重启前后根对照）。
- **边界（2026-10-26 定）**：`onlyProject` 仅 status echo（`/cg status` 的 `only-project=on/off` 反映配置值），**不参与作用域判定**；on/off 下根外会话都 skip。`cwd===''` 的会话按 `unattributed` 放行（旧行为，宿主正常会话带 cwd），**不计入外部隔离承诺**，不写 Release。

### 11. R-MEMROOT：记忆根按项目根隔离（v0.6 单根模型，随 1.0 签收）

- **验什么**：`memoryRoot` 相对**唯一项目根**解析；根来源优先级：**显式配置 > 持久化状态 > 首次推断**；未配置推断出的根**必须持久化**、**重启沿用、不重新推断**、不随会话/cwd 漂移；根外会话=外部（不得跨根读写记忆）；推断失败 → `no-project-root` 且不落记忆；**根变化**（配置变更 / 持久化丢失 / 换机）必须在 `/cg status` + 审计可见（`project-root-changed` / `inferred-fresh`）；**已写记忆不迁移、不删除**，留原根；发布包不预填绝对路径；status 显示「根 / 记忆根 / 来源（配置|推断）」。

### 11.1 载体 A 验收补充（用户级状态文件；并入第 11 条签收）

状态文件：`$DSH_HOME/context-governance/root-state-<profile>.json`，实例键 `DSH_PROFILE`；字段 `{version, root, source:'inferred', inferredAt, inferredFromCwd, instance:{profile}}`；不写进仓库/发布包。

1. **身份来源（2026-10-26 修订）**：身份 = 宿主 `ctx.get('profileContext')`（要求 `name`/`dir` 合法；`home` 可选，有则 anchor=home，无则 anchor=dir）；**env 不再作为身份来源**。缺失/非法 → 不猜键、不落盘，报「持久化身份不可得」+ 审计，root 保持 unknown（fail-closed）；非 profile 启动同样 fail-closed。
2. **根推断**：按会话 cwd 上溯含 `.git` 的最近祖先；realpath + Windows 盘符大小写归一；结果必须是存在的目录、非相对路径、不落在 `$DSH_HOME` 内。
3. **首次推断成功**：落盘 + `inferred-fresh`（带 `inferredFromCwd`）；失败 → `no-project-root`、不换根、等下个会话再试。
4. **重启沿用**：状态文件存在则不重推；启动 cwd 换到别处也不影响（fake fs/env 单测 + 真机一条）。
5. **状态丢失/损坏/version 未知**：按未持久化处理 → 重推 + `inferred-fresh`；旧记忆不迁移不删；status 显示新根；不得崩溃。
6. **配置 vs 持久化**：config 与持久化根不同 → config 优先 + `project-root-changed(from/to/source)`；**config 移除后回落到持久化根，同样审计并写进文档**（新增，防「删配置后突然变根」）。
7. **原子写**：tmp+rename 或独占创建（`wx`）；写失败不阻断主流程 → 降级「本次不持久化」+ 审计。
8. **首次推断并发（新增）**：两会话同时首次需要 → 只允许一个写成功（`wx`/锁），另一个读回同一根；禁止互覆盖/根翻转。
9. **多 profile 不串根**：两个 `DSH_PROFILE` 各写各文件、互读不到；profile 值做文件名安全化（防路径穿越）。
10. **根未知时**：`/cg status` 显示 `project-root: unknown (no-project-root)`；提前压/保护/header/mem_* 全部 skip 或拒绝并审计，**不写任何记忆**。
11. **schema**：读取时校验类型/版本；未知字段容忍、坏值按损坏处理；不得因解析失败崩溃。
12. **不进仓/不进包**：状态文件不写进仓库或发布包；扫描 0 命中；测试用临时目录。
13. **权限（低优先）**：文件仅当前用户可写（用户目录 ACL 继承即可）；写权限失败不影响功能、记审计。
