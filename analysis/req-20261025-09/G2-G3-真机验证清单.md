## 2. G2-A 安全时机（turn 已结束 + agent idle）

**操作**：在隔离实例新会话里连发 6–8 条 1–2k 字消息（凑出可压区间），等 `turn/end`；探针在 `turn/end` + **50ms** 调 `engine.compactNow(agent, signal, 'probe-g2a')`；若 busy，**+500ms 重试一次**，记录哪次成功（这就是实测 safe delay）。

**期望信号**：
- probe log：`G2A attempt t=… delay=50ms` → `G2A ok elapsed=…ms`；
- 探针收到事件序列 `compaction/start` → `compaction/summary` → `compaction/end`，`seq` 严格递增；
- 隔离审计 `.tmp/native-test-ws/memory/governance/audit.jsonl`：`compaction-cost` 且 `trigger:"manual"`、`auditVersion:"cost-v1.4"`、`tokensBefore`(tokenMeter) / `tokensAfter`(tokenMeter 或 usage)、`compactionId` 非空；
- 隔离实例 `/cg status`：`last-compaction: id=… manual=true ok=true … failures=none`；`last-cost: before=<大> after=<小> trigger=manual …`。

**失败长相**：
- reject 且 `name=ManualCompactionError`、message 含 `busy` → **turn/end 不是安全时机**，G2 fail（不 arm）；
- reject 且 message 含 `already has active work` → 同上，同时坐实 review P3-1（插件当前会映射成 `failed` 而非 `busy`）；
- resolve 但 30s 内无 `compaction/start` → 假成功，G2 fail；
- `compaction/start` 后 120s 无 `end`，或 `summary` 为空/不可读 → 事件流不完整，G2 fail；
- 宿主拒绝（如“无可压区间”）→ 记 `nothing-to-compact`，加大种子消息后重跑，不算 fail。

**证据**：`.tmp/g2-probe.log`；隔离 `audit.jsonl` 的相关行；`/cg status` 快照 `.tmp/g2-status-A.txt`。

## 3. G2-B turn 中失败形态（pre-step）

**操作**：另开新会话；探针在 `agent/pre-step`（step=1）调用 `compactNow(agent, ac.signal, 'probe-g2b')`，其中 `ac.abort()` **已先执行**（确保即使进入压缩也立刻中止）。

**期望信号**：2s 内 reject（busy 或 `AbortError`），**无** `compaction/start`；probe log `G2B outcome=rejected name=… elapsed=…`。

**失败长相**：
- resolve（宿主允许 turn 中压缩）→ **严重发现**：记 `G2B=accepted`，立即 abort 后续并报 00；0.2.2 必须禁止 pre-step 路径；
- 5s 挂起 → 记 timeout；
- 出现 `compaction/start` 且未及时收尾 → 记事件流污染。

**证据**：probe log 本段 + 该会话事件类型计数。

## 4. G2-C 事件流 / 审计完整性（复用 G2-A 会话）

**操作**：压缩结束后 /cg status + 审计抽查。

**期望**：
- 审计无 `cycle-interrupted`、无 `duplicate-cycle-start`；
- `last-reinjection: status=injected …`（或按保护项明确 skip）；若出现 `manual-compaction-loss`，逐项记 `failures`；
- 事件流：`compaction/start.seq < summary.seq < end.seq`，且之后 `turn/end` 正常。

**失败长相**：缺 summary/end；审计出现 interrupted；回注失败计数上升。

## 5. G3-1 `measure()` 即时性（4 个取样点）

**取样点**（探针每次记：`nodes` 数、Σ`tokens`、`contextPressure.surfaceTokens/pressureTokens`、最近 `assistant/message.usage.tokens`）：
1. `agent/pre-step` step=1（turn 开始，验证 `surface` 是否已含新用户消息）；
2. `turn/end`；
3. `compaction/end` 后 microtask（验证压后是否立刻下降）；
4. 下一轮 `agent/pre-step`（验证是否含回注/新消息）。

**期望**：turn 边界 Σmeasure 与 `surfaceTokens` 同量级（±10% 或 ±2k tokens）；`compaction/end` 后 Σmeasure 明显下降（≈summary 大小）；下一 pre-step 已更新。

**失败长相**：
- `measure()` 返回 null/0 而 `surfaceTokens` 很大 → 该时机不可用；
- 压缩后仍为旧值、且要到下一 `assistant/message` 才更新 → 记 `stale`（插件 T8-2 已有 usage 兜底，需确认 `tokensAfterSource` 走 `usage` 而非 `none`）。

**证据**：`.tmp/g2-probe.log` 的 `G3 point=…` 行 + 审计 `compaction-cost.tokensBeforeSource/tokensAfterSource`。

## 6. G3-2 `effective` 口径

**操作**：压前/压后各取一次隔离实例 `/cg status`。

**期望**：
- `pressure: measured=… estimated=… adjusted=…(×1.35) effective=… ratio=… window=1.00M (session …) at=0.60 effective<at`；
- `effective = max(measured, adjusted)`、`adjusted = estimated × 1.35`、分母 = 1,048,576（`window=` 来源 `projection`）；
- 压后 measured/estimated/effective 同向下降。

**边界**：本会话规模远低于 native（0.6934），"`effective ≥ native−0.02` 不抢"**无法在本例真机触发**；记为“公式可落地，近 native 分支未真机验证”（与 Release notes 已知限制一致）。
