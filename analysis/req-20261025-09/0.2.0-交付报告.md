## 4. 语义口径（写给复核/需求）

- `compact.at` = 占窗口比例，默认 `0.60`；`native` 动态上限 `floor(min(W×0.8, W−O−65536))/W`；`at > native` 拒绝（**M2 不支持推迟**）。
- `compact.early` = 纯配置 `on|off`；`research` profile 默认 `off`；**0.2.0 没有引擎通道状态**（`early-channel` 是 0.2.1 的字段名）。
- 项目层**不可信**：禁安全参数、`at ≥ 0.45`、任一键被拒即整层退回；`policy-invalid` 审计 + `/cg status` 双通道可见。
- 压力：`measured`（usage 实测）、`estimated`（tokenMeter）、`adjusted = estimated × estimateSafety`（系数只读配置文件）、`effective = max`；缺项写 `-`。
- 会话层：**进程内**覆盖（0.2.0 未取宿主 session id，不宣称按会话隔离）；重启失效；`reset` 清空。
