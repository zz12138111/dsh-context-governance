## 2. `/cg policy show` 四层合成 + 每层 `source`

```
/cg policy show
```

期望结构：
- 第 2 行摘要：`compact.at=… (source=…<层名>) native=0.6785 early=on|off`
- `layers:` 链：空层标 `(empty)`，例：`plugin (empty) -> project -> session (empty)`
- `session: none`（或已 `/cg set` 的键值）
- 每键一行：`<key>=<value> (source=builtin|profile=…|plugin|project|session)`
- 无拒绝时 `invalid: none`

## 4. 项目层真读（两小步，**需要两次重启**）

**4a 有效文件 → `source=project`**

```powershell
# 重启前：
Set-Content "D:\DS-PROJECT\DSH插件开发\.cg-policy.json" '{"compact.at":0.52}' -Encoding utf8
# 重启 DSH（用户/00 执行）→ 然后：
/cg status      # 期望 policy: compact.at=0.52 (source=project) native=0.6785 early=on
/cg policy show # 期望 layers: plugin (empty) -> project -> session (empty)
```

**4b 含安全参数 → 整层拒绝 + policy-invalid（需再重启一次）**

```powershell
Set-Content "D:\DS-PROJECT\DSH插件开发\.cg-policy.json" '{"compact.at":0.52,"compact.lowThresholdAck":true}' -Encoding utf8
# 再重启 → 然后：
/cg status      # 期望 policy: compact.at=0.60 (source=builtin) … + policy-invalid: 1 (project/compact.lowThresholdAck:project-denied)
/cg policy show # 期望 invalid: compact.lowThresholdAck (source=project): project-denied — 项目层禁改安全参数
```

**收尾（必须）**：删掉临时文件，再重启一次回到干净状态：

```powershell
Remove-Item "D:\DS-PROJECT\DSH插件开发\.cg-policy.json"
```
