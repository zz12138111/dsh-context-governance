## 2. 关键口径（与 DEC-66 对齐）

- **选取**：`current` 跟 `#lastSession`（最近观察到的本项目会话）；`window=` 后带 session 短 id；展示用 current，**校验用 conservative = min(已观察)**。
- **中途变化**：每次新窗口观察**立即重算** native（`resolve()` 现算，不锁 apply），并触发运行时校验；`request/context` 无 `contextWindow` → **删除置 unknown**，不沿用。
- **无观察**：`window=unknown`、`native-current` 回退配置并标 `config-fallback`、`validated=false`；允许设 `at` 但状态标 `unvalidated`。
- **数值/退化（DEC-20261025-68 A）**：`nativeFromWindow`：`W` 非正整数 → unknown；`W ≤ O+65536` → **`unknown (degenerate)`**（禁造 0/0.6785）；否则 `floor(min(W×0.8, W−O−65536))/W`。退化时设置 `at` 的层一律拒绝（`native-uncomputable`），继承值标 `unverified-degenerate`，`W` 恢复自动恢复可校验。
- **两种“不可算”要区分**：**无观察**（未收到任何窗口）→ 允许设 `at`、标 `unvalidated`；**退化**（收到窗口但不可算）→ **拒绝设置**。
- **`W` 防御**：观察值只在 `Number.isInteger(W) && W > 0` 时记录（`#observeWindow`）。
- **性能**：`windowState` 为纯计算（无 `stateOf` 调用、无 materialize），status 每次只取一次；`stateOf` 的缓存/live 引用约束见 `DEC-PLUGIN-20261025-40`（0.2.1 不调用 `stateOf`，直接用事件观察值，等价且更省）。
