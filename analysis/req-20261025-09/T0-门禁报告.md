## 3. 逐项结论

| 门禁 | 结论 | 证据/判断 |
|---|---|---|
| **G1** 能否取 `agentPresets` 与 preset 引擎 | **不通过（初判）** | 根级插件 scope `ctx.get('agentPresets')=absent`；无 `serviceFor` 路径。`agents` 服务可见（`list`/`get` 为函数），但尚未验证 `agent` 对象上是否暴露 preset/compaction —— **这是唯一的替代路线，需补一轮 agent 级探针**（`agents.list()` 取 agent 后查 `serviceFor`/`presets`/`compaction`）。 |
| **G2** `compactNow` 安全时机/失败形态 | **部分**（源码级，未运行时验证） | 宿主 `@deepseek-ai/dsh-compaction-basic/lib/index.js:985-1011`：`compactNow` 走 `agent.runMaintenance`，非 idle（有唤醒队列任务）时抛 `ManualCompactionError('busy')`；会压缩整个可选区间；不调 pruner。=> 安全时机=**turn 结束、agent idle**；turn 中调用必然 busy。运行时失败形态待 0.2.1 的 gate 用例验证。 |
| **G3** 各时机 `measure()` 是否反映当前上下文 | **部分** | 探针即时取 `tokenMeter` 为 `absent`，@ready 后治理看到 `get.tokenMeter=obj`（存在但晚挂载）；`llm=absent`（窗口信息需另找路径）。`effective=max(measured,estimated×1.35)` 口径本身可落地（usage=measured、tokenMeter=estimated），但 "各时机 measure 是否即时" 未验证，需 agent 级探针 + 真实 turn 边界取样。 |
