# 1.0 缺陷登记：提前压对「项目外会话」生效，但保护/回注/成本全不生效

- 登记：2026-10-26 03:25（UTC+8），版本 1.0.0（pid 21372），登记人：开发
- 状态：**待排期，未修复、未改任何配置**
- 严重度：**高**（默认开 + profile 级安装 → 本机任意工作区会话）

## 现象（现采）

外部会话（00 会话，cwd=`G:\DS-HARNESS`）在 19:15 被提前压：

```json
{"ts":"2026-10-25T19:15:39.925Z","event":"early-decision","sessionId":"session-53ece2c2-6726-4550-8d89-e7ac24e4ebc6","action":"force","reason":"forced","effective":0.602,"threshold":0.6,"native":0.6934}
{"ts":"2026-10-25T19:15:58.373Z","event":"early-forced","sessionId":"session-53ece2c2-6726-4550-8d89-e7ac24e4ebc6","accepted":true,"compaction":"committed","failures":[],"delayMs":50,"effective":0.602,"threshold":0.6,"native":0.6934}
```

压缩确实发生（不是没执行）：

- 同会话 19:20:32 再决策：`action=skip reason=cooldown effective=0.065`（上下文已从 60.2% 降到 6.5%）
- 该会话投影 `contextTimeline.seq=39950`，time=1792955758366（= 19:15:58.366Z），`cat=inject name=compact-checkpoint` → 压缩摘要已注入

但该 cycle **没有任何** `protection-write` / `reinjection` / `compaction-cost`（03:24 复查仍无）。

对照组（本项目会话，同一条 early 路径，19:18）：

- `protection-write` 4 条 → `protection-materialized` → `manual-compaction-loss` → `reinjection(seq=28226)` → `compaction-cost`（context-zip 全套：tokensBefore=468008 → tokensAfter=4037，backendUsage.input=438530）

## 判定

- **不是「延迟未落」**：观测入口对该会话直接 `return`，该进程内不会补落。
- **不是「early-forced 路径没发 cost」**：同一路径在本项目会话正常发。
- **是缺陷**：动作面（early wiring）跨项目执行，观测面（guard）只处理本项目 → 项目外会话被压，但零保护、零回注、零成本账。

## 根因（代码）

- `src/compress/runtime.js:1456`：`#belongsToProject(session)` 为 false 直接 return（P2-1 设计：不写本项目记忆、不回注到别的会话）——这一层本身正确。
- `src/compress/early-wiring.js:93-202`：`check()` 只判 policy/压力/agent/冷却，**无项目归属过滤**；`index.js:516` 接线时也没传 `projectRoot`/`onlyProject`。
- 结果：`early-forced` 的 `compaction:"committed"` 是 wiring 的 fallback（`early-wiring.js:172`，fresh report 为 null 时也写 committed），`protection/reinjected/compactionId` 因 null 被审计白名单剥离 → 审计看起来“成功”，实际无人核对。

## 影响

1. 默认开下，任何非本项目工作区会话在 effective≥0.60 都会被压掉，且不做 latest-user/rules/rollback 回注、不记账；首个实证就是 00 自己的会话。
2. 本项目的 `audit.jsonl` 混入外项目 sessionId（轻）。

## 修复建议（未实施）

1. early wiring 拿到与 guard 同源的项目判定（guard 暴露 `belongsToProject(session)`，或接线传入 projectRoot 做同样的词法比较）；非本项目 → **skip + 审计 `early-skipped reason=foreign-session`**，不取 agent/engine。
2. `early-forced` 在无 fresh report 时 `compaction` 写 `null`/`unknown`，不写 `committed`。
3. 回归：本项目会话仍有 protection+reinjection+cost；外部会话 `compactNow` 调用 0 次（spy 单测）。

## 复现

任意外部工作区会话 `turn/end` 且 `effective ≥ compact.at`（当前 0.60）→ `early-forced`，无 cost。
