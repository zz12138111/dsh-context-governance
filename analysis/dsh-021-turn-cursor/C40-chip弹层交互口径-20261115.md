# C40 / B3 chip 弹层交互 + 文案精简（用户验收项；2026-11-15 用户要求本版优化）

> 背景：rc.11 真机点输入框下方「压 45%」chip，弹层**向下/向左弹出**、离 chip 远、压住正文，用户评「很怪」；并追加「**气泡也不用搞太大，字太多，能用简化的说明说清楚即可**」。（截图 `G:\DS-HARNESS\.dsh-file-attachment\image-27.png`）
> **定级（审核）**：**体验优化项/用户验收项 B3，不是需求缺口**；与 B1/B2/P3-c 同批进 **rc.12**，不单开版本；**不并入"实现缺口 3 项"计数**，不改变"终版功能满足"判定。
> 本文只定"用户能看到什么算对"，不规定实现。

## 1. 弹出方向

- **默认向上弹**：弹层底边贴 chip 上沿，覆盖对话区。
- **仅在 chip 上方可用空间 < 弹层高度 + 16px** 时翻到下方（顶边贴 chip 下沿，间距同 §2）。
- **禁止向左/右弹出**；禁止打开后跳位或换向（先定方向再出现）。

## 2. 面板尺寸（"不要大块面板"）

- 宽度 **≤ min(360px, 视口宽 − 16px)**；高度 **≤ 260px**（含操作按钮行），超高**内部滚动**。
- **主视图至多 3 行文字**：①数值行（如 `45%`）②状态行（如 `本会话·已保存`）③生效行（如 `重启后仍生效`）。
- 每行 **≤ 18 个汉字**（数值行不受限）；**不铺长句、不并列同义说明**。

## 3. 文案精简（"字太多"）

- 主视图**不得出现**（出现即判不过）：`source=` 等技术字段、`session:A1`/`session:A2` 层级代码、"本次修改写入"这类流程短语、括号里的多重说明。
- 允许且推荐的三句（**与 `verify-c40-popover` 断言一致**）：保存 `45%` ／ `本会话·已保存（重启保留）` ／ `重启后从已保存值读回`；**reset** `58%` ／ `已清除本会话覆盖` ／ `重启后仍生效`。空间极窄时可用短形等义（「已保存」+「重启后仍生效」），但**不得出现「重启失效」并列**。
- **技术细节进二级**：`详情`/展开/悬浮/设置页里看（一次点击可达），默认收起。
- **与 B1 合并后的唯一文案规范**：
  - 保存成功主视图必须出现「**本会话·已保存（重启保留）**」**且**附注「**重启后从已保存值读回**」；**不得出现「重启失效」**；
  - **reset 后**主视图出现「**已清除本会话覆盖**」+「**重启后仍生效**」（数值回 `58%`）；
  - 主视图不放层级代码；技术字段只在详情/设置页；
  - `via` 若在 UI/审计里展示，只写**类型名**（`origin`/`sec-fetch`/`token`），**不得写死**某一值、不得出现 token 原文。
  > B1 原判据（主标签「本会话·已保存（重启保留）」）**按等义写法接受**：`本会话·已保存` + `重启后仍生效` 即满足，只要不出现矛盾并列。

## 4. 锚点与避让

- **不得遮挡输入区（硬线）**：向上弹 → 弹层底边 ≤ 输入框顶边 − 4px；向下弹 → 弹层顶边 ≥ 输入框底边 + 4px；弹层与输入框、发送按钮、chip 行**矩形交集为 0**。
- **水平对齐**：弹层水平中心与 chip 中心偏差 **≤ 8px**（chip 靠右时可右对齐，偏差仍 ≤8px）。
- **正文避让**：空间足够时，弹层与**最后一条消息区域**重叠 = 0；空间不足允许覆盖正文，但**绝不盖输入框**。
- 打开/关闭弹层不得改变对话滚动位置（不跳动）。

## 5. 屏幕边缘

- 任意边距窗口 **≥ 8px**（不越界、不裁切），宽>1200 / 窄≈800 / 矮<700 三档都成立。
- 靠右/靠左时整体平移贴边，**不做左右翻转**；上方不足翻下方后，仍须满足 §4 全部几何。

## 6. 关闭

以下**每一个都必须能关**，关后焦点回 chip、再点能重开：
1. 点弹层外部任意处；
2. 按 `Esc`；
3. 再点同一 chip（toggle）。
另：**切换会话/工作区自动关闭**；发送消息时关闭（不残留到下一轮）。

## 7. 验收判据（测试/审核可对表判定）

**截图 3 张（真机）**：宽>1200 正常态 / 窄≈800 / 矮<700（触发向下翻转）。
**离线**：rect 几何断言（含翻转、贴边、输入框避让），不给"看起来差不多"式结论。

**每张截图须同时满足**
- 弹层在 chip 上（或翻转后在下），与 chip 间距 **≤12px**、中心水平偏差 **≤8px**；
- 输入框、发送按钮、chip 行完整可见且与弹层**无交集**；
- 边距 **≥8px**，无裁切；
- 主视图 **≤3 行**、每行 **≤18 汉字**、**无 `source=`/层级代码/流程短语**。

**出现任一条即判不过**
- 向左/向右弹、跳位/换向；
- 与 chip 间距 >12px 或水平偏差 >8px；
- 遮挡输入框/发送按钮/chip；
- 边距 <8px 或被裁切；
- 主视图 >3 行、出现技术字段、或"重启失效"与"重启保留"并列；
- 点外部 / Esc / 再点 chip 任一关不掉；切换会话后残留。

## 8. 与既有条款关系

- 复用 `C12`（chip 文本 `压 NN%` 与快照一致）、`C32`（四层标签字面）；本项只约束**弹层几何 + 主视图文案精简**，不改四层标签定义。
- **B3 与 B1 文案规范合并为一条**（§3），避免两处口径打架；B1 仍按实现缺口记、B3 按用户验收项记。

## 9. B9：操作区常驻（百分比输入框 + 四个按钮；2026-11-15 用户追加；用户验收项，并入 rc.16）

> 真机反馈：百分比输入框仍在滚动区，改数值得先滚轮；要求与按钮同批常驻。**定级=体验项/用户验收项，不计实现缺口**；**与 B8 合并成一门「操作区常驻」**（B8 的按钮常驻 + B9 的输入框常驻同门验收）。**rc.15 可装，但该门未满足 → 被 rc.16 取代。**

- **门名与内容（合并门）**：`操作区常驻（B8+B9）`——footer 必须**同时包含百分比输入框与四个按钮**（恢复默认 / 恢复全局 / 保存 / 打开设置页），**全部无需滚动即可见、可聚焦**；详情展开后仍成立；输入框与按钮**不在** `data-cg-body` 滚动容器内、与 body 同级。
- **排布（用户明确要求，2026-11-15 修正）**：**输入框为窄框（宽度 48–64px，含 `%`），固定在按钮行左侧、垂直居中**；**四个按钮必须全部可见，不得被输入框挤掉**；宽度不足时**按钮换行成两排**（输入框跨两排居中），**不允许输入框占满整行**、不允许把输入框退回滚动区。
- **版面硬边界（2026-11-15 rc.17 修订为自适应）**：**footer 不设高度上限、不得用 `overflow:hidden` 裁切**（@360 约 70，@280/@320 约 108，极端 5 排约 184，均须完整可见）；**面板 `maxHeight` 仍 260px**；**内容区保底动态**：`bodyFloor = min(96, max(0, 260 − footer实测 − chrome))`（极端档允许 32，body 内部滚动）；**与对话 composer 的交集硬线已按用户 2026-11-15 裁定豁免**（记录措辞：「C40 硬线『弹层与 composer 交集=0』经用户裁定豁免；现状形态被认可」，**不得写"已满足/已实现避让"**）；**3 个控件（输入框 + 两按钮）任一被裁切即判不过**；**能力变化（B14）**：删除「恢复默认」后，回内置默认需先清全局值（`/cg set reset` 或设置页），页面不得宣称"一键回默认"。
- **行为**：输入框可聚焦/可键入，数值校验走 `C9`/`C10`；保存/恢复沿用 B2 刷新链路。
- **验收判据（不滚动即可见）**：
  1. 打开面板→**不做任何滚动**：输入框与四个按钮 rect 全在面板可视区内；`elementFromPoint(输入框中心)` 命中 `input`，`elementFromPoint(各按钮中心)` 命中对应按钮；
  2. 点「详情」展开后，上述仍成立（无需滚动）；
  3. 输入框与按钮**不在** `data-cg-body` 内；**输入框宽度 48–64px 且不占满整行**；**四个按钮全部可见**（允许换两排）；五个控件全在面板内且无裁切；面板高度 ≤260px；与 composer 交集 = 0；极端窄档 body 可降至 32 但必须可滚。
- **判不过**：需要滚动才能看到/聚焦输入框；被详情挤出视口；输入框在滚动容器内；**输入框占满整行或宽度 >64px 把按钮挤掉**；**四个按钮任一不可见**；footer >88px、面板 >260px、body <96px 或与 composer 有交集。
