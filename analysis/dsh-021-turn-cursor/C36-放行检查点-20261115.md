## 0. 用法

本单只给**可观测的放行判据**，不写实现方案。逐项记 PASS/FAIL，全部 PASS 才可对外宣称「全纳管」（另须 P1/P2/P3 齐，见 `REQUIREMENTS.md:487`）。任一 FAIL → **不放行**，按「撤回本轮」流程处理（撤回声明 + 本轮作废 + 不发），不改判据迁就结果。

## 3. CP1–CP8 逐项判据

### CP1 无 `.git` 也受治（C36 ①）
- 动作：两会话各跑至少一次普通对话；触发一次真实压缩（用户手动 `/compact`）。
- 现采证据：该 session 的审计行（`protection-write`/`protection-materialized`/`reinjection`/`compaction-cost`）、`/cg status` 的 `project-root`（应显示 `root=<realpath(cwd)>`，不因无 `.git` 变 `unresolved`）。
- **PASS**：两会话都有治理审计 + 压缩策略生效 + 保护/回注事件；`project-root` 明确非 unresolved。保护/回注须有**真实压缩**后的 `protection-write`/`reinjection` 才算（需求 ⑪，`ae957da`）；无真实压缩只判「已纳管」。
- **FAIL**：任一会话无审计、或 `project-root: unresolved`、或需 `.git` 才纳管。

### CP2 每会话压缩比（C36 ②）
- 动作：设 0.55 / 0.65 → 重启 → 两会话各 `/cg status`。
- **PASS**：两会话 `at` 分别 = 0.55 / 0.65，且 `source` 标 `A2`（或 C36 ② 的等价字面）；重启前后值不串、不丢。
- **FAIL**：值互相污染 / 重启回退默认 / 只有全局一份。

### CP3 层级取值（C36 ③）
- 动作：对同一会话依次造 A1（会话内 `/cg set`）、A2（持久化）、cwd 项目配置、plugin 全局四层可用值，观察生效值与 `source`。
- **PASS**：`A1 > A2 > cwd > plugin` 逐层可核；`policy-resolved` 审计与 `/cg status` 的 `source` + 最终值一致（需求 ⑩：字面固定 `session:A1`/`session:A2`/`project`/`plugin`，大小写敏感，禁 `session/A2`/`A2`/`persisted` 等别名，两处同一枚举）。
- **FAIL**：层级顺序错 / `source` 缺失或与生效值不符 / 只能看结果不能看来源。

### CP4 A2 落盘（C36 ④）
- 动作：写 0.55/0.65 后查 `~/.dsh/context-governance/`；再查两项目根**无**新增策略文件。
- **PASS**：文件内键=完整 session id、值含 `at/source/updatedAt/version`；重启可读回；项目根未新增。
- **FAIL**：键被截断/复用、写进项目根、重启读不回。

### CP5 `root-unresolved` 不静默（C36 ⑤）
- 动作：造 cwd 异常（造法见 §4）→ 看审计与该会话是否仍受治。
- **PASS**：审计出现 `root-unresolved{sessionId,cwd,reason}`，**每会话每 cycle ≥1 条**、同 cycle 去重；该会话**仍**压缩/审计/回注；且**不参与 `compaction-loss` 分型**（loss 行 `failures` 不含它）。
- **FAIL**：无审计 / 重复刷屏 / 会话被降级成不干预 / 混进 loss 分型。

### CP6 显式关闭留痕（C36 ⑥）
- 动作：一会话置 `out-of-scope`（或 `observe-only`），跑一次压缩。
- **PASS**：不干预，但有审计；且 **`observe-only` 仍写压缩事实/成本**（取不到数值写 `null`/`unknown`，不得因 observe-only 缺行——需求 ⑨，`ae957da`）。
- **FAIL**：静默 / 仍保护 / 因 observe-only 缺成本行。

### CP7 子会话不写记忆（C36 ⑧，沿用多根 #2）
- 动作：在该会话下起一个 subagent / 子会话。
- **PASS**：子会话纳管压缩与审计，**不建记忆写路径、不注入 header**；根归属按 #2（父根继承 / 自身 cwd / session 级）。
- **FAIL**：子会话写记忆或注入 header。

### CP8 证据边界（C36 ⑦）
- **PASS**：报告明确写「本轮在无 `.git` 会话下采集，rc.2 两轮不覆盖此格」；证据含两 session id、两工作区路径、建会话方式、重启时刻、审计行号。
- **FAIL**：拿 rc.2 证据顶 C36。

## 4. 负向造法（不做 ACL 手术）

- **空 cwd / cwd 消失**（首选）：在 `%TEMP%` 下建临时目录 → 在其中起会话 → **删除该目录** → 观察 `root-unresolved`。可逆、无提权、不碰其他项目。
- **cwd 不可读**：以「目录被删除」覆盖该分支；**不采用改 ACL/权限**的做法（需 UAC、且可能波及其他目录）。
- **cwd 不可写**：若需求坚持，只在**独立临时目录**上用只读介质/挂载验证，且须用户批 + 写明还原步骤；否则标「未覆盖」并如实上报，不得默认 PASS。
- 任何负向动作前确认目标是上述临时路径，动作后立即还原并记录。
