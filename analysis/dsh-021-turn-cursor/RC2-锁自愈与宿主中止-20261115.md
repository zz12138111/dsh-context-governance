## 1. 陈旧写者锁自愈（`src/memory/lock.js`）

**背景（实测）**：`.writer.json` 记录的 pid 35560 早已不是 DSH 进程，但 `process.kill(pid,0)` 返回 **EPERM**；`isPidAlive` 把 EPERM 当存活、锁文件又没有过期回收 → 每次启动都判"有活写者" → memory store 只读 → guard 只读 → 审计全停（`runtime.js:1213`）。复验时锁龄已约 5 小时。

**实现**：

| 项 | 内容 |
|---|---|
| 三态探测 | 新增 `probePid(pid)` → `alive` / `denied`(EPERM) / `dead`；`isPidAlive` 保留兼容 |
| 判陈旧 | 新增 `evaluateLockStaleness(lock, { now, staleMs, probe })`：`dead` 立即陈旧；`denied` 需锁龄或心跳超阈值；`alive` 只有"自带心跳且心跳停摆超阈值"才陈旧（覆盖 pid 复用），**没有心跳的旧格式锁一律按活写者处理**（不抢旧版本活进程的锁） |
| 阈值 | `DEFAULT_STALE_LOCK_MS = 10 分钟`、`LOCK_HEARTBEAT_MS = 45 秒`（均可参数覆盖） |
| 心跳 | 持锁期间每 45s 原子重写 `heartbeatAt`（`unref()`，release 停止） |
| 留档 | 回收前把旧锁复制成 `.writer.json.stale.bak`（与损坏锁的 `.bak` 分开） |
| 不静默 | `acquireWriterLock` 返回 `reclaimed = {reason, probe, pid, startedAt, lockAgeMs, heartbeatAgeMs}`；`MemoryStore` 收进 `status.lockReclaimed` + `warnings`；`src/index.js` 写根审计 `stale-lock-reclaimed` + logger warning |
| 审计字段 | `pid` / `lockProbe` / `lockAgeMs` / `startedAt` 入 `AUDIT_FIELD_WHITELIST`；`stale-lock-reclaimed` 入 `AUDIT_EVENTS` |

reclaim 原因取值：`pid-dead`、`pid-unprobeable`（EPERM+超龄）、`heartbeat-stale`（存活但心跳停摆）。

**没有按"pid 不属于 DSH 进程组"实现**：插件跑在宿主进程内，不启动子进程就无法跨平台枚举进程组。改用心跳（对自家写者严格更强的存活信号）+ 超龄探测；对"pid 被非 DSH 进程复用"的场景由 `heartbeat-stale` 覆盖。若后续要更严格，可给锁加 `hostPid`/启动时间戳再比对，属 rc.3。

## 2. `compaction/end` 带 `error` 按 host-aborted（`src/compress/runtime.js`）

宿主事件声明（asar:341262）：`'compaction/end': { compactionId; sourceCommandId?; turn: number | null; error?: string }`。典型来源是 `@deepseek-ai/dsh-compaction-basic/summarizer` 的 shrink 检查（asar:755928）：`summary is not smaller than the shadowed content (...)`。

**实现**：`compaction/end` 分支最先判 `event.data.error`（非空字符串）：

- 不核对、不写 `compaction-loss`、不写 `compaction protection failed` warn、不写诊断行；
- 记 `#record({ skipped: true, reason: 'host-compaction-error', checks: [], failures: [] }, null)` → 报告 `compaction=skipped`、`protection=ok`；
- 丢弃该 compactionId 的 pending state；若存在 early 预写则归档（`archiveProtection(reason='host-compaction-error')`）；
- `stats.aborted += 1`；只留一条 `logger.info('compaction aborted by host ...')`。
