## 结论

**rc.11（`222a718`）是否满足 1.1.0 终版功能需求：实现面满足（0 实现缺口），终版整体不满足——差距只剩"真机门未跑"（rc.11 未装机）。**

**A. 实现缺口：0（六项收口，逐条证据）**
1. **P2 `type/status` 不持久** → `b92d0bc`；门 **3/3**。
2. **P3 审计落根/字段分账** → `56009d4`+`1baa586`；门 **6/6**（miss 12 行全落会话根、header 两行同根且带 `sessionId`、`pointers` 落盘、`lines` 真实行数）。
3. **P4 根被删后重建** → `2bea17d`；门 **5/5**（不重建、两模式写 `root-unresolved`、`memory show` 不显伪根）。
4. **P5 UI 写被拒/`via`** → `da29d52`+`b059266`+`1baa586`；门 **16/16**（三证任一 + loopback 强制；`via: origin|sec-fetch|token`；三拒因）。
5. **P5 装配级（mount 漏传 `csrfToken`）** → `7ec4e84`；**门从 mount 处抓 handler 真打**：两个 mount 入口 token-only → 200 + `via:'token'`，mount 未配 token → 403 `missing-proof`，`plugin-policy-persisted` 恰 1 行含 `via` 不含 token 值。**A/B 实证：`1baa586` 15/16 红 → `7ec4e84` 16/16 绿**（上一版作废正是因此项）。
6. **P6 registry 空 id 崩溃** → `1baa586`（`registry.js:461`/`:211`/`:440`；新增 `no-session-id` 每 cwd 一次；历史 137 次属既有缺陷）。

**B. 真机未跑（唯一差距主体，rc.11 未装机）**：C5 #4 三项、C8（D2 显示）、C11①②③（三类 UI 写 + `via` + 两条 curl 负向）、C24–C26（A2 读回/隔离/持久化，绑定新包重读）、C27/C29（`reset` 回落 + UI 入口）、C28（文案）、C31（三类 UI 写 + 真机读 `via` + 负向）、C32（四层标签）、C35（真实压缩）、C37 值级回归（rc.10 CP3 双向基线）、C38（P2/P3/P4 真机复验 + miss 去重复核 + P4 根移走）、C39 第二 DSH_HOME；**CP1–CP9 在 rc.11 全部待重跑**（rc.10 的 CP1/CP2/CP3/CP4/CP7 仅作基线；CP5 不可造、CP6 无入口）。

**C. 已知边界（均非缺口，Release notes 必写）**
1. `/cg policy show` 的 `layers:` 不含 A2、A1 标签写 `session`（显示级；`policy:` 行来源正确）。
2. `user-store:` 分隔符混用（cosmetic）。
3. `compaction-loss{rollback-point,b-class}` 假告警（需求裁 B；`8097e0a`/`d868e3a` 起改判 pass + `protection-covered`，旧事件不删）。
4. CP5 真机不可造（宿主 cwd 校验直接 `turn/end error`，离线覆盖）；CP6 `observe-only` 无入口（审核裁定记未覆盖）。
5. C39 第二 DSH_HOME 未覆盖（SKIP 不计 PASS）。
6. token 由快照下发、本机进程可读（真边界是 loopback；Release notes 须写"不要把监听暴露到非 loopback"）。
7. P3 路由只覆盖**带 sessionId 的记忆类事件**；`root-registered`/`policy-resolved`/`memory-store-open` 等无会话事件仍落用户级主审计（P3 门 INFO 已记）。
8. `/cg set` 命令面不带 `via`（无 HTTP 凭据来源），只有 UI 写入口带。
9. `root-missing` fail-closed：根移走/网络盘断开 → 记忆写拒 + `memory show` 显 `(root-unresolved)` + 不重建目录（P4 要求）。
10. 新增审计事件 `no-session-id`（每 cwd 一次）与 reason `root-missing`；`da29d52` 历史"勿出包"标注已被 `b059266` 收口；`compliance-scan` 对解包目录假绿（出包=仓库级+包内双跑）。
