## 结论

**rc.11（`222a718`，已装机）是否满足 1.1.0 终版功能需求：不满足——实现缺口 3 项（P3-c、B2、B1）+ 其余真机门未跑。**

**A. 实现缺口：3 项（阻塞"满足"、不阻塞 rc.11 已装使用）**
1. **P3-c｜UI 触发写路由的审计仍落主根**：G 根会话 UI 保存 `policy-set` 两行落 **D 根**审计（`04:39:36/42`）、reset 落 G 根（`04:41:21`）——命令面/UI 面审计归属仍回落主根。依据 `:462`（每会话按自身 cwd 归一为**记忆/审计归属**）。修法：UI 写路径与事件面同一 root 解析（与 P3/P3-b 同源）。
2. **B2｜reset 成功后 UI 不刷新**：气泡仍显本会话 A2、输入框仍 45，未回 58%/plugin。依据 `:1183` C8①生效值②来源层 + `:1188` C26「文案与实际一致」。修法：reset 成功后重新解析生效层并刷新气泡/输入框（值+来源+生命周期三件同刷）。
3. **B1｜生命周期文案冲突（用户拍板「该修修掉」，审核 §15）**：保存成功主标签必须为「**本会话·已保存（重启保留）**」；若并列运行时层，须附注「**重启后从已保存值读回**」；**禁止「重启失效」与「重启保留」并列**（用户看到 A1 与 A2 并列即矛盾）。依据 `:1183` C8 生命周期「按层唯一映射、不得混用别名」+ `:1188` C26 文案与实际一致。**门口径提醒**：测试 `7559912` 的 B1 门 **5/5 为假绿**（只验写层字符串、未验「来源层标签 + 写入层文本」渲染组合，审核已要求重写）——不据该门改判，B1 仍按缺口记；重写后的门须断言渲染组合与"禁并列"负向。
> 已收口（离线证据保留）：P2 `b92d0bc` 门 3/3、P3 `56009d4`+`1baa586` 门 6/6、P4 `2bea17d` 门 5/5、P5 `da29d52`+`b059266`+`1baa586` 门 16/16、**P5 装配级** `7ec4e84`（门从 mount 抓 handler 真打；A/B 15/16→16/16）、P6 `1baa586`。**真机正向：P5 PASS**（UI 保存/reset 均 `via:'token'`、A2 已清、plugin 落 0.6）。

**B. 真机未跑（其余差距）**：C5 #4、C11②（设置页专验 mount 已正向 PASS，余 plugin 落盘复核）、C24–C26（A2 读回/隔离/持久化重读；C26 现因 B2 红）、C27（`/cg set reset` 命令面）、C28（文案）、C31 两条 curl 负向、C32（四层标签）、C35（真实压缩）、C37 值级回归、C38（P3-c 修后复验 + miss 去重 + P4 根移走）、C39 第二 DSH_HOME；**CP1–CP9 在 rc.11 全部待重跑**（CP5 不可造、CP6 无入口）。

**C. 已知边界（均非缺口，Release notes 必写）**
1. `/cg policy show` 的 `layers:` 不含 A2、A1 标签写 `session`（显示级；`policy:` 行来源正确）。
2. `user-store:` 分隔符混用（cosmetic）。
3. `compaction-loss{rollback-point,b-class}` 假告警（需求裁 B；`8097e0a`/`d868e3a` 起改判 pass + `protection-covered`，旧事件不删）。
4. CP5 真机不可造（宿主 cwd 校验直接 `turn/end error`，离线覆盖）；CP6 `observe-only` 无入口（审核裁定记未覆盖）。
5. C39 第二 DSH_HOME 未覆盖（SKIP 不计 PASS）。
6. token 由快照下发、本机进程可读（真边界是 loopback；Release notes 须写"不要把监听暴露到非 loopback"）。
7. P3 路由只覆盖**带 sessionId 的记忆类事件**；`root-registered`/`policy-resolved`/`memory-store-open` 等无会话事件仍落用户级主审计（P3 门 INFO 已记）。
8. `/cg set` 命令面不带 `via`（无 HTTP 凭据来源），只有 UI 写入口带。
9. `root-missing` fail-closed：根移走/网络盘断开 → 记忆写拒 + `memory show` 显 `(root-unresolved)` + 不重建目录（P4 要求）。
10. 新增审计事件 `no-session-id`（每 cwd 一次）与 reason `root-missing`；`da29d52` 历史"勿出包"标注已被 `b059266` 收口；`compliance-scan` 对解包目录假绿（出包=仓库级+包内双跑）。
11. **B1 已改判为实现缺口（用户拍板「该修修掉」）**，不在此列；判据与修法见 A 段第 3 条（审核 §15）。
