## 结论

**rc.11（`1baa586`）是否满足 1.1.0 终版功能需求：不满足——实现缺口 0（P2/P3/P4/P5/P6 全收口），差距只剩"真机未跑"（rc.11 未装机）。**

**A. 实现缺口：0（`1baa586` 收口 5 项，逐条证据）**
1. **P2 `type/status` 不持久** → 已修 `b92d0bc`；门 `verify-c38-pointer-roundtrip` **3/3**（重开后索引与 `mem_query` 均保持）。
2. **P3 审计落根/字段分账** → 已修 `56009d4`+`1baa586`；门 `verify-p3-audit-root` **6/6**（`memory-pointer-miss` 12 行全落会话根、主根 0；`header-injected`/`header-truncated` 同根且两行均带 `sessionId`；`pointers` 进白名单落盘；`lines` 为真实文本行数）。
3. **P4 根被删后重建** → 已修 `2bea17d`；门 `verify-c38-root-deleted-no-rebuild` **5/5**（不重建、两模式均写 `root-unresolved`、`memory show` 不显伪根）。
4. **P5 UI 写被拒 / `via` 未达** → 已修 `da29d52`+`b059266`+`1baa586`；门 `verify-c31-write-route` **11/11**（三证任一 + loopback 强制；200 带 `via: origin|sec-fetch|token`，优先级 origin→sec-fetch→token，token 值不入响应/审计/日志；拒因 `missing-proof`/`cross-origin`/`not-loopback`）。
5. **P6 registry 空 id 崩溃** → 已修 `1baa586`（`registry.js:461`/`:211 #noteNoSessionId`/`:440` 双保险；新增 `no-session-id` 每 cwd 一次）；该 reason 历史累计 137 次，属既有缺陷、非 rc.10 新引入。
> **另一处被绿门掩盖、已在本包修掉**：`mountPluginPolicyRoute` 未转发 `csrfToken` → plugin 层 token-only 写必 403 `missing-proof`（C11② 17/17 只覆盖 origin 路径故未暴露）；`1baa586` 修复 + 补用例。

**B. 真机未跑（唯一差距主体，rc.11 未装机）**：C5 #4 三项、C8（D2 显示）、C11①②③（三类 UI 写 + `via` + 两条 curl 负向）、C24–C26（A2 读回/隔离/持久化，绑定新包重读）、C27/C29（`reset` 回落 + UI 入口）、C28（文案）、C31（三类 UI 写 + 真机读 `via` + 负向）、C32（四层标签）、C35（真实压缩）、C37 值级回归（rc.10 CP3 双向 PASS：`0.5 source=project` → 删文件 `0.58 source=plugin`）、C38（P2/P3/P4 真机复验 + miss 去重复核 + P4 根移走矩阵）、C39 第二 DSH_HOME；**CP1–CP9 在 rc.11 全部待重跑**（rc.10 已有 CP1/CP2/CP3/CP4/CP7 读数作基线；CP5 不可造、CP6 无入口）。

**C. 已知边界（均非缺口，Release notes 必写）**
1. `/cg policy show` 的 `layers:` 不含 A2、A1 标签写 `session`（显示级；`policy:` 行来源正确）。
2. `user-store:` 分隔符混用（cosmetic）。
3. `compaction-loss{rollback-point,b-class}` 假告警（需求裁 B；`8097e0a`/`d868e3a` 起改判 pass + `protection-covered`，旧事件不删）。
4. CP5 真机不可造（宿主 cwd 校验直接 `turn/end error`，离线覆盖）；CP6 的 `observe-only` 无入口（审核裁定记未覆盖）。
5. C39 第二 DSH_HOME 未覆盖（SKIP 不计 PASS）。
6. token 由快照下发、本机进程可读（真边界是 loopback；Release notes 须写"不要把监听暴露到非 loopback"）。
7. P3 路由只覆盖**带 sessionId 的记忆类事件**；`root-registered`/`policy-resolved`/`memory-store-open` 等无会话事件仍落用户级主审计（无会话可归属，P3 门 INFO 已记）。
8. `/cg set` 命令面不带 `via`（无 HTTP 凭据来源），只有 UI 写入口带——真机核对时"命令面行无 `via`"不是缺口。
9. `root-missing` fail-closed：根目录被移走/网络盘断开 → 记忆写拒 + `memory show` 显 `(root-unresolved)` + **不重建目录**（P4 要求）；真机矩阵应加"根移走"一条。
10. 新增审计事件 `no-session-id`（每 cwd 一次）与 reason `root-missing`；`da29d52` 历史"勿出包"标注已被 `b059266` 收口；`compliance-scan` 对解包目录假绿（出包=仓库级+包内双跑）。
