## 4. 临床诊断字段的真实性（审核核过代码，**读法以此为准**）

| 来源 | 是否可信 | 说明 |
|---|---|---|
| DOM `[data-cg-portaled]` / `[data-cg-panel]` 是否存在 | **可信** | wrapper 带 `data-cg-portaled="1"`（`client.js:912`），只在 portal 成功后才进 DOM；失败时 `return null`（`:916-919`）→ **DOM 里没有** |
| console `popover-rect` 的 `portaled` 字段 | **不可信（恒 true）** | `client.js:792` 是**硬编码 `portaled: true`**；该行在渲染前由 effect 打印，无法得知后续 `portalToBody()` 的结果 |
| `intended` / `measured` / `corrected` 三值 | **可信** | 由实测 rect 计算（`:789-791`） |
| console `portal unavailable; popover hidden` | **可信** | 仅 portal 失败时打一次（`:917`） |

**因此窗口判读顺序**：①先看 DOM 有没有 `[data-cg-portaled]`（有=portal 生效）；②有则看 `intended` 与 `measured` 偏差；③没有则看是否打了 `portal unavailable`。
**已知诊断噪声**（不阻塞本包，下版修）：`portaled` 恒 `true`——应改为记录 `portalToBody()` 的真实返回值，或把该行移到渲染之后。
