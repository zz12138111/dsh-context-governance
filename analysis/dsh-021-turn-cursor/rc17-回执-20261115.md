## 11. ⛔ 再作废原因：B12（「打开设置页」静默 no-op + 用户决定删除）

- **现象**（`image-37.png`）：footer 的「打开设置页」点击无反应。
- **性质**：`onClick: () => { try { ctx?.openSettings?.(); } catch {} }` —— 宿主不提供 `openSettings` 时**静默无动作**（可选链 + 空 catch），属**实现缺陷**："看得见点不着"。同时用户决定**直接移除**该入口（设置页仍可从 DSH 设置进入）→ 记"实现缺陷 + 产品取舍"两条。
- **处置**：rc.17 作废；rc.18 移除该按钮，footer 控件 5→4、按钮计数 5→3；Release notes 写"气泡不再提供设置页入口"。
- **教训**：**不允许渲染"可能永远 no-op"的控件**——要么不渲染，要么给可见反馈；`try/catch` 吞异常不能当作"容错"。
- **另立待证 B13**：`image-37.png` 中气泡底边疑似压到 composer 行（C40 硬线要求交集=0）。等 00 取 panel / composer 两个 rect；若相交则 B13，另单处理。
