## 1. 本轮修什么

测试在 rc.7 上发现一条 INFO：`mergePluginPolicy` 的「volatile 有值优先」分支在 apply 里**走不到**——`resolveConfig()` 重建 `policy` 时丢弃了 `at`，生产只能靠持久文件兜底，该分支是死路。

`2ba0b4e` 把它激活：
- `resolveConfig()` **原样保留 `policy.at`**（数字或 `.volatile()` 引用）；
- 新增纯函数 `resolvePluginAt(config, { persistedAt, persist })`：volatile 合法值 → 以其为准**并回调落盘**；为空 → 持久值；都无 → null（沿用配置默认）；
- `mergePluginPolicy()` 改用它；新增 5 条用例（volatile 优先+落盘回调、`.get()` 引用可读、非法 volatile 回落持久值、`resolveConfig` 不丢 `at`、apply 侧 `source=plugin`）。

**影响面**：设置页保存路径不变（仍走写路由落盘 + `rebuildPolicies()`）；持久值仍只替代 plugin 默认、不越级压 A1/A2/project；新增"宿主自己把 volatile 带进 apply 时以它为准并同步落盘"。
