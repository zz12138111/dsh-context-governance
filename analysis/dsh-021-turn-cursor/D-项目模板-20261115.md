# D：项目模板 `.cg-policy.json`（显式、可选、可见）

依据：`REQUIREMENTS.md` :457 / 项目模板安全口径（2026-11-15 改）。

## 行为

- **默认没有项目层**：仅当 `<root>/.cg-policy.json` 存在且显式写了该字段才生效；不隐性回退读别处。
- **格式带 schema 版本**：写入 `{version:1, values:{...}}`；读取兼容旧扁平映射；未知版本/坏 JSON/非对象 → `policy-invalid(source=project)`，**整层不生效**。
- **可见**：`/cg status` 输出 `project-template: {...} (source=.cg-policy.json)` 或 `project-template: none`；`/cg project-template show` 输出中文「项目模板 <值>（来源 .cg-policy.json）」/「无项目模板」。
- **显式创建/清除**：`/cg project-template create compact.at=0.5` / `/cg project-template clear`；创建经 `validateLayer({source:'project',projectLayer:true})`（`estimateSafety`/`lowThresholdAck` 等仍被拒）；审计 `project-template-set{path,keys}` / `project-template-cleared{path}`。
- 层级不变：**A1 > A2 > 项目模板 > plugin**。

## 文件

- 新增 `src/project-template.js`（解析/序列化，纯函数）。
- `src/index.js`：项目层读取改用解析器；`policyState.projectTemplate` 暴露 `{path, exists, values, write, clear}`。
- `src/commands/cg-status.js`：status 行 + `project-template` 子命令。
- `src/audit.js`：事件 `project-template-set`/`-cleared`，字段 `keys`。
