# C11③ 实现记录：UI 会话级写入口（chip/气泡 → A2）

日期：2026-11-15　角色：开发　判据：C11③（RC 阻塞）+ C32（终版）+ C28/C8 文案

## 需求口径

- 主入口（`conversation.composer.dock` 的 chip「压 xx%」+ `conversation.input.overlay` 气泡）保存 = **写本会话 A2**（重启保留），**不得**写 plugin/project；
- 设置页（`settings.section`）= **只写 plugin 全局层**，文案明示「全局（影响所有会话）」；
- C32：四层固定标签 + `builtin`/`profile=<name>` 映射，`/cg status` 与 UI **同字面、禁别名**。

## 关键发现（宿主能力）

- `conversation.composer.dock` 与 `conversation.input.overlay` 的 slot 契约都是 `scope: 'session'`，标准 props 含 **`sessionId: SessionId`**（`@deepseek-ai/dsh-cordis-client-runner/src/client/slot-catalog.ts:931/1685`）。
  → 浏览器侧**能拿到会话标识**，A2 写入口可实现，不属于「被宿主卡住」。
- 客户端没有命令执行面（`inject` 只有 `slots/locale/configForms`），因此写入走**同源 HTTP 路由**：新增 `POST /context-governance/session-policy`。

## 实现

| 位置 | 内容 |
|---|---|
| `src/session-policy-route.js`（新） | `createSessionPolicyHandler` / `mountSessionPolicyRoute`：只收 POST；`{sessionId, at}`；sessionId 白名单 `^[A-Za-z0-9._:-]{1,120}$`；at ∈ [0,1]；Origin≠Host → 403；体限 4 KiB → 413；坏 JSON → 400；入口缺失 → 503；命令链拒绝 → 409 带 `detail` |
| `src/index.js` | `sessionWriteRef`：把写请求交给 **`/cg set compact.at=<at>` 同一条命令链**（校验/审计/A1+A2 双写全复用，避免两套规则漂移）；写入成功后 `rememberSessionPolicy()` 刷新快照口径，避免保存完仍显示旧值；路由随 `ctx.inject(['webServer'])` 挂载并在 dispose 置空 |
| `src/ui-labels.js`（新） | `LAYER_LABELS` + `layerLabel`（`profile=<name>` 单独展开、`session` 历史字面按 A1 显示、未知原样透传） |
| `src/policy.js` | `/cg status` 与 `/cg policy show` 的摘要行在既有 `source=/native=/early=` 之后并列 `层=<中文标签>`（C8「键名 + 中文」，不改既有口径与顺序） |
| `src/settings-policy.js` | `sessionOverride` 由 `source === 'session'` 改为 `startsWith('session')`（C36 字面变更后的死字段修复） |
| `lib/client.js` | chip/气泡读 `props.sessionId`；保存 → `saveSessionAt` → POST；无会话标识时按钮禁用并显示「不会退化为全局写入」；设置页保留 `configForms`（plugin）+ 「保存为全局」文案 + 「本会话已自定义，全局修改不影响本会话」提示；内联同一张标签表 |

## 已知边界

- 写路由依赖命令面（`commands`）：宿主未挂载时返回 503，UI 显示原因，**不退化写全局**。
- 真机需验：chip/气泡保存后 `压 xx%` 数值刷新、重启后仍为本会话值、设置页改动不影响已自定义会话。
