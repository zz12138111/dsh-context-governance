# C38：会话级记忆隔离——实现设计（2026-11-15，开发）

依据：`REQUIREMENTS.md` C38 ①–⑭、`docs/适用范围与已知限制.md`、架构 §8.1、审核三份裁定。**本文件只定实现方案，代码未开始。**

## 1. 数据模型（指针层在插件、正文在文件）

```
<home>/context-governance/sessions/<完整 sessionId>/
  MEMORY.md          # 指针索引（短行：ID + 一句话摘要）
  topics/<type>.md   # 指针条目（指向正文 文件:行号）
  .id-watermark      # 本会话 id 高水位（复用 D-MGMT-023 机制）
shared/<rootId>/
  MEMORY.md / topics/  # 跨会话共享（仅 promote 进入）
```

- 指针 id：`MEM-<sessionShort8>-YYYYMMDD-NNNN`（隔离命名空间；同会话内单调，复用 D-MGMT-023 高水位）。
- 指针体：`{id, type, title, target:{file, line}, summary, status, role?, originSessionId?, importedAt?}`。
- 正文权威：`G:\DS-HARNESS\memory/OPEN.md|decisions/|DEFECTS.md|ARTIFACTS.md` 等人工文件；插件**只读目标行做可解析性校验**，绝不写正文。
- 存量 `<root>/memory/governance/` 标 `legacy-shared-v1`：只读、默认不注入。

## 3. 关键判据落点

- ① 指针可解析：append 时校验 `target.file` 存在且 `line` ≤ 行数；运行期 query/header 时复算，失配标 `miss` + 审计 `memory-pointer-miss`，**不回滚正文、不阻塞登记调用方**（登记失败只返回 warning）。
- ③ 正文缺失/行漂移 → `miss`；**登记失败不阻塞正文写入**（正文由人工先写）。
- ④ header：只输出 `MEM-<short>-… · <一句话>` 短行；条数/字节上限触发截断 → 审计 `header-truncated{bytes,limit}`；不复制正文。
- ⑤⑥ 共享：默认不共享；`promote` 显式写入 `shared/<rootId>/`，带来源 sessionId；同根两会话互不可读；重启保留（home 下文件）。
- ⑦ 子会话：不写；默认不读父（`isSubagent` 时库为空/只读）。
- ⑩ 存量：`<root>/memory/governance` 标只读；`import --from legacy` 显式导入并审计，不自动迁移。
- ⑪⑬ `--from-role`：role 必须显式设置；按“同 role + 同 rootId 最近活跃会话”找源，找不到 → 报错 + `memory-import-no-source`；复制生成新 id + `originSessionId/originRole/importedAt`，原会话不动；跨角色只能 promote。
- ⑭ 负向：默认不继承（新会话空库）；role 缺失/无源会话报错；继承指针同①可解析。

## 4. 测试计划（新增 `test/c38-session-memory.test.mjs` + 扩展）

1. 两会话同根：A 登记指针、B 不可读；重启后各自保留（fake home）。
2. `miss`：正文删除/行漂移 → query/header 标 miss + 审计；登记调用方不阻塞。
3. header 截断：超条数/字节 → 截断 + `header-truncated`，无正文复制。
4. promote → `shared/<rootId>`，B 可见；带 `memory-promoted` 与来源 sessionId。
5. legacy：`<root>/memory/governance` 只读、默认不注入；`import --from legacy` 生成新 id + `memory-imported`。
6. `--from-role`：role 设置 + 复制 + 原会话不变 + `memory-imported-role`；无源 → 报错 + `memory-import-no-source`。
7. 子会话不写/不读父；root-unresolved 会话仍有库。
