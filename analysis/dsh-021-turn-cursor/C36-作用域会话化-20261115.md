# C36 ①：会话作用域化（`.git` 不再是闸门）

依据：`REQUIREMENTS.md` C36①/#9、R-SCOPE；审核 `C36-实现裁定` / `C36-放行检查点`。

## 改了什么

| 位置 | 内容 |
|---|---|
| `src/roots/identity.js` | 新增 `inferCwdRoot(cwd, {exclude})`：cwd 存在且可读 → `realpath(cwd)` 归一即根（不要求 `.git`）；不存在/不可读 → null。 |
| `src/root-state.js` | 再导出 `inferCwdRoot`。 |
| `src/roots/registry.js` | `resolveSessionRoot`：无 git 祖先时用 `#cwdRootFor(cwd)` 兜底；cwd 归属根**即便不是主根也纳管**（`managed = viaCwdRoot \|\| #isManaged(...)`），`.git` 不再是治理闸门；空 cwd 仍 `no-root/cwd-missing`（`root-unresolved` 由 pool 审计）。 |
| `src/compress/root-guards.js` | ① 会话首个事件写根审计 `session-governed{sessionId,root,rootId,source,subagent}`（每会话一条）；② 无根/不可用 cwd 会话写 `root-unresolved{sessionId,cwd,reason,cycle}`，**每会话每 cycle 去重**（事件不带 cycle 时沿用该会话最近 cycle），不参与 `compaction-loss`。 |
| `src/audit.js` | 新增事件 `session-governed`、`root-unresolved`；白名单新增 `cwd`。 |

## 测试

- 新增 `test/c36-scope.test.mjs` 4 例：`inferCwdRoot`（无 git cwd/不存在/空）、registry 无 git 祖先 → managed（cwd 根）+ 空 cwd → no-root、pool `session-governed` 每会话一条、`root-unresolved` 同 cycle 去重/跨 cycle 再写且不写 loss。
- 口径同步两处旧断言：`roots-registry` T7（原“无 git → no-root”改为“cwd 根纳管”）、`mem-routing-interface` T14（`NO_ROOT` 改用空 cwd 触发）。
- 全量：`node --test "test/*.test.mjs"` = **597 / 597 pass**（rc.3 基线 593，净增 4）。

## 边界

- 无根会话（空/不可读 cwd）当前只保证“不静默 + 审计”；记忆/保护不落该会话（记忆需根）。
- 子会话仍不写记忆（沿用多根 #2）；显式关闭/能力缺失照旧 observe-only。
- 未安装、未同步 profile、未启用、未重启；不 push。
