# C36 ②③：A2 持久会话层 + 层级与 source 字面

依据：`REQUIREMENTS.md` C24–C30/C36②③⑩、审核 `C36-实现裁定`。

## A2 存储（`src/a2-store.js`）

- 位置：`~/.dsh/context-governance/session-policy.json`（用户级，不写项目根）。
- 键 = 完整 session id；值 = `{at, source:'session:A2', updatedAt, version:1}`。
- 重启可读回；`maxEntries=500` + `ttlDays=90` 兜底淘汰，淘汰写 `a2-evicted{count,reason}`；
  损坏/未知版本按“无 A2”处理并写 `a2-load-failed`，不抛错；原子写、mode 0600。

## 层级与接线

- `buildPolicyState(config, { a2Store, onPolicyResolved })`：
  - 会话层值对象用 Proxy：写/删 `compact.at` 即持久/清除 A2（UI 保存与 `/cg set` 同源）；
  - 层序 **A1（session:A1）> A2（session:A2）> cwd（project）> plugin**；
  - `policy-resolved{sessionId,at,source}` 写根审计（每会话按 source|at 去重）；
  - 暴露 `a2For(sessionId)` 供 status/测试。
- `apply`：创建 A2 store；`a2AuditSink` 优先写根审计（用户级），失败退回 logger。
- `audit`：新增 `a2-evicted`、`a2-load-failed`、`policy-resolved` 与字段 `at`/`entries`。
- 文案：`lifecycleText`/`lib/client.js` 映射 `session:A1`→临时、`session:A2`→已保存（重启保留）。
- `cg-status`：`/cg set` 的 <0.30 拦截与 `(rejected)` 标记改按 `startsWith('session')` 判层（source 升级为 `session:A1`）。
