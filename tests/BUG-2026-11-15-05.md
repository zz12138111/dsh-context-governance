## 现象（用户说法）

点「保存到本会话」成功后，气泡面板三行同时出现：

- 来源层：`本会话·临时（重启失效）`（`source=session:A1`）
- 生效时点：`本会话有效，重启后失效`
- 本次修改写入：`本会话（session:A2，重启保留）`

用户读成「保存白存了」。

## 根因（代码定位）

- `lib/client.js:277`（`bubbleView`）与 `:311`（`renderBubbleText`）写死了
  `writeLayerTextFor('session')` → 恒为 `session:A2，重启保留` 文案（`LABELS.zh.writeLayerSession`，`:42`）；
- 而来源层/生效时点两行是**按快照 `source` 动态**算的（`:275`/`:276`、`ui-labels.js:16`/`:46`）。
  保存后宿主解析结果是 `session:A1`（A1 = 本会话即时值，A2 = 落盘值；两者都存在时来源报 A1），
  于是「动态两行说 A1=重启失效」与「写死一行说 A2=重启保留」并排，语义冲突。

**不是数据错**：保存确实既写 A1 又落 A2，只是文案没交代「A1 即时 / A2 落盘」这层关系。

## 修法（rc.11 不动；建议进 1.1.1）

1. `writeLayerTextFor(entry, { source } = {})` 增参，按快照来源分档：
   - `source` 为 `session:A1` → `本次修改写入：本会话（A1 即时生效；已落 A2，重启后从 A2 读回）`
   - `source` 为 `session:A2` → 保持 `本会话（session:A2，重启保留）`
   - 其它（plugin/project/未保存）→ `本次修改写入：本会话（保存后 A1 即时生效，并落 A2）`（描述"保存会做什么"，不再用完成时）
2. `bubbleView` / `renderBubbleText` 传 `snapshot.source` 进去；生效时点行对 A1 可加括注
   `本会话有效，重启后失效（重启后从 A2 读回）`，与写入层同义。
3. 不改四层标签本身（`ui-labels.js` 的 A1/A2 定义是正确的事实描述）。

## 用例（1.1.1 验收）

- `bubbleView({at:0.45, source:'session:A1'})` → 第 3 行含 `已落 A2` 且含 `重启后从 A2 读回`；
  第 1/2 行仍是 `本会话·临时（重启失效）` / 含 `重启后失效`（**两层都如实**）。
- `renderBubbleText({at:0.45, source:'session:A1'})` → 同上口径（气泡与设置页共用视图模型，不许两套）。
- `bubbleView({at:0.45, source:'session:A2'})` → 仍 `session:A2，重启保留`（不许把 A2 说成临时）。
- `bubbleView({at:0.6, source:'plugin'})` → 写入层描述"保存会做什么"，不含"重启保留"完成时断言。

## 结论

文案缺陷，**不阻断 rc.11 装机验收**；修复排 **1.1.1**，与 B2 同批改（同一视图模型）。
