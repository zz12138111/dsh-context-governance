# REQ-20261025-01 M1 任务拆解

> 依据：`REQUIREMENTS.md` 的 `REQ-20261025-01`；架构 `docs/上下文治理插件-架构说明-v1.0.md`。
> 状态：待开发接单；优先级 P0。
> 顺序：先门禁（E1/E2）后实现；T1 与 T2 可并行。
> 交付：每个任务只交摘要 + 证据路径 + 关键数字 + 验证项；长日志/截图落盘，不整段贴回。
> 红线：不得改本机已装插件/配置/DSH；实验用隔离 profile 或只读方式；需要安装/重启先报 00 + 用户批准。

## T1 E1/E2 实验与行为矩阵

- **目标**：确认宿主默认与 context-zip 的感知层级、摘要可读性、回注形态表现。
- **做法**：
  - E1：观察压缩事件、`/compact`、状态推断三层，记录哪一层可用；
  - E2：只读测试三种回注形态（详情 / 标题+指针 / ID+状态），记录被吞、重复、接续效果。
- **产出**：实验记录（路径）、6.3 行为矩阵要填的字段、E2 默认形态建议。
- **验收**：E1 至少“状态级”；E2 给出默认形态与理由。
- **限制**：只读；不改用户现有 context-zip 配置；需要动插件/重启先报 00。

## T2 记忆文件与契约

- **目标**：内置最小文件存储，能记任务态、可追溯、可并发保护。
- **产出**：
  - `MEMORY.md` 索引 + 主题文件；
  - 记忆写入/查询工具（名称待定，暂称 `mem_write` / `mem_query`）；
  - 条目字段：`id/type/status/project/title/detail/source/writer/confidence/时间/supersedes/evidence`；
  - `proposed/active/superseded/expired` 状态；
  - 原子写 + 进程内单写者队列 + 外部修改检测。
- **验收**：字段完整；高风险默认 `proposed`；并发写不损坏；检测到外部修改会告警/只读；不写敏感信息。
- **测试**：临时项目目录；不碰用户数据。

## T3 压缩适配与保护

- **目标**：宿主默认 + context-zip 两个后端可用；保护清单生效；失败可回退。
- **产出**：
  - 适配器（行为契约字段：控制权、感知层级、摘要权威/可读性、改写边界、契约自检）；
  - 能力探测/版本矩阵；
  - 保护校验：最新用户消息、规则注入、工具配对、批次清单、回滚点；
  - 冲突检测（provider 占用、宿主动态、版本、控制权）；
  - 后端选择与回退宿主。
- **验收**：双后端各跑一遍；不替换用户 context-zip 配置；受保护内容零丢失；冲突/不可用有显式报告；自检失败走降级。
- **依赖**：T1 的行为矩阵。

## T4 回注与覆盖判断

- **目标**：压缩后只放 ID/状态/指针，不产生第二段摘要。
- **产出**：
  - 读摘要视图（可读时）；
  - 覆盖判断（ID 优先、标题关键词粗匹配）；
  - 三形态：已覆盖→ID+状态+指针；未覆盖→加一行标题；不可读→仅 ID+状态；
  - 冲突时记忆赢；
  - 回注预算与“被吞”审计。
- **验收**：详情永不回注；摘要不可读可用；冲突可标记；回注被吞有记录；模型能按指针找回详情。

## T5 状态命令与审计

- **目标**：用户和 00 能一眼看到当前状态与降级。
- **产出**：
  - 状态命令（暂名 `/cg status`）：后端、能力、记忆条数（active/proposed）、上次压缩、上次回注、降级项；
  - 审计事件（JSONL）：后端、压缩前后、成本归属、回注被吞/重复、失败；
  - 实测/估算成本分列。
- **验收**：状态输出可读；审计字段齐全；不把估算混进实测净节省。

## T6 失败与降级

- **目标**：所有失败路径可预期、可回退、显式告警。
- **产出/验收**：
  - 记忆写失败：重试一次；仍失败跳过本次压缩并告警；
  - 压缩失败：回退宿主默认；再失败保留上下文报错；
  - 摘要不可读：ID+状态；范围/产物不可见：只读；
  - 配置非法：插件不加载，DSH 正常；
  - 插件禁用：无行为残留。
- **测试**：故障注入；记录每条路径的证据。

## T7 验收场景 S1–S6

- **目标**：按需求单的 S1–S6 跑通，留证据。
- **产出**：测试脚本、运行记录、结果表、证据路径。
- **验收**：
  - S1 压缩后接续，不重问；
  - S2 批次进度接上；
  - S3 新会话 header 带偏好；
  - S4 受保护内容零丢失；
  - S5 摘要不可读只回注 ID+状态；
  - S6 后端不可用/配置非法时回退或插件不加载，DSH 正常。
- **复核**：开发自测；独立复核由审核打包执行（00 派发）。

## 建议节奏

1. **门禁阶段**：T1 + T2 并行；E1/E2 未过则暂停 T3/T4，回报需求调整范围。
2. **实现阶段**：T3 → T4 → T5/T6。
3. **验收阶段**：T7 自测 → 审核打包独立复核 → 00 转用户验收。
