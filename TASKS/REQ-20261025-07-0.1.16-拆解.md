## T3 成本字段拆分（P3-2）

**当前问题**：0.1.15 把展示串写进 `compaction-cost.backend`（如 `host-basic (inferred)`），破坏枚举。

**目标结构**：
```
backend:          "host-basic" | "context-zip" | "unknown"   ← 只写枚举，兼容 0.1.14
backendKind:      "host-basic" | "context-zip" | "unknown"   ← 与 backend 同值
backendLabel:     "host-basic (inferred)" 等展示串
backendInferred:  true | false
auditVersion:     "cost-v1.4"
```

- `backendInferred=true` 仅当实际探测 kind 为 `none`/`unknown`、由推断补位时；
- 实测可得时 `backendInferred=false`，`backendLabel` 可等于 `backend`；
- 无观察时：`backend="unknown"`、`backendKind="unknown"`、`backendLabel="unknown"`、`backendInferred=false`；
- 混合形态：`backendInferred=true` + `backendLabel="mixed (unverified)"`，`backend` 仍写枚举（取不到就 `unknown`）。
