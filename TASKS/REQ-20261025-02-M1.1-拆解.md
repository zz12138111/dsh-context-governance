## T2′ prune 观测与成本接入（唯一新增实现）

**输入**：宿主 `compaction/prune` 事件（`shadowedRange` / `shadowedSeqs` / `shadowedTokenCount`）+ 紧随的替换 `tool/result`（`sourceEventSeqs` 引用原事件）。

**处理**
1. 每条 prune 写一行审计 `prune-observed`：
   - `sessionId`、`seq`、`shadowedStart`、`shadowedEnd`、`shadowedTokenCount`、`replacementSeq`；
   - `tool`：用替换事件的 `callId` 反查本会话的 `tool/call` 得工具名；反查不到记 `unknown`，**不猜**；
   - `cycle`：`auto` / `manual` / `outside`（归属见下）。
2. **去重**：同一 `shadowedRange` 只记一次（重放/重复事件不重复计数）。
3. **周期归属**：上次 `compaction/end` 之后、本次 `compaction/summary` 之前的 prune 记 `cycle=current`；其余记 `outside`（只进会话累计，不进单周期成本）。
4. **成本聚合**：写 `compaction-cost` 时带：
   - `tokensPruned`（本周期 `shadowedTokenCount` 之和，`cost-v1.2`，来源 `measured`）；
   - `pruneCount`；
   - `pruneTools`（最多 5 项，`name:count`）；
   - `auditVersion='cost-v1.2'`（只增字段，不改 v1.1 语义）。
5. **状态命令**：`/cg status` 与 `/cg status last-cost` 增加 `pruned=<tokens> tools=<top5>`；无 prune 显示 `pruned=0`，不报错。

**禁止**
- 不得改写任何 `tool/result` 内容、不得 `session.append` 替换事件、不得写 spill；
- 不得读工具结果正文做归因（只允许 `callId`/`seq`/元数据）；
- 不得改宿主 pruner 配置、不得替换或禁用宿住 pruner；
- 不得把无数据写成 0 冒充“已测”（无 pruner 环境 → `pruneCount=0` 且 `tokensPruned=null` + `unknown`，二者要区分）。

**失败处理**：事件形状不符 → 仍然记 `shadowedTokenCount`，`tool=unknown`；异常只 log/audit，不抛宿主；不得静默。

**验收**：见 T7′ ①②③⑤⑦。
