### B2 差异表模板（按此填，别自由发挥）

每个维度填三列：**宿主 pruner 现状 / M1.1 目标 / 处置（复用｜自研｜不做）**。

| 维度 | 宿主 `tool-result-pruner` | M1.1 目标 | 要回答的问题 |
|---|---|---|---|
| 触发时机 | 压缩触发时（压力/溢出） | 结果入史即折（持续） | 早折的收益能否用 B1 基线证出来？证不出就复用宿主时机 |
| 阈值/保留 | 8192 码点；头 4096 + 尾 1024 | 8000 字符；头尾各 1500 | 差异是否值得另立一套参数？不值得就对齐宿主 |
| 工具范围 | 全部文本结果（含 `pwsh`/`read`） | 白名单；绝不折 `pwsh`/`read` | **必须自研的部分**（硬约束） |
| 替换协议 | `session.append` + `compaction/prune` 影子定价 + `sourceEventSeqs` | 同协议 | **必复用**，不自研 |
| 原文留存/回读 | 留会话日志，靠回放取 | spill 文件 + 原生 `read` 指针 | 是否需要 spill？取“能原生 read 回读”为增量，否则复用日志 |
| 配置项 | `thresholdChars/headChars/tailChars` | `fold.*` 一组 | 命名与语义对齐，避免两套阈值打架 |
| 审计/成本 | `compaction/prune` 影子价 | `cg-fold` 审计 + 成本归属 | 增量，自研 |
| 与 tokenGuard | 无感知 | 跳过已折结果 | 增量，自研 |

**结论只回答一句**：T2 走「复用宿主协议 + 只做增量」还是「独立实现」，并给工作量与风险差。

## T2 折叠核心

- **触发**：结果长度 ≥ `minChars`（默认 8000）、工具在名单内、未被折叠、不是最近 `keepRecent`（默认 3）条。
- **名单**：`grep`、`web_fetch`、`dsh_browser_content`、`cross_session_read`、`job_output`、`history_search`；**不含 `pwsh`、`read`**。
- **固定格式**：
  ```
  [cg-fold] tool=grep chars=48213 kept=1500+1500 omitted=45213
  <头 1500 字符>
  …[省略 45213 字符，完整内容见指针]…
  <尾 1500 字符>
  [cg-fold] full: <spill 路径>（用原生 read 按 offset/limit 读取）
  ```
- **验收**：中间必须有“省略 N 字符”；N = 原文 − 头 − 尾；替换发生在进入历史前；`pwsh`/`read` 永不折叠。
- **失败**：写 spill/替换失败 → 保留原文、audit、显式告警。
- **范围调整**：若 B2 差异表显示宿主 pruner 已覆盖大部分，**先报需求**再改 T2 范围；不得自行扩大或缩小。

## T3 spill 存储与原生 read 回读

- 目录：`~/.dsh/context-governance/spill/<session>/`；
- 原子写；权限收紧；不进 git、不进记忆；
- TTL 7 天、总量默认 256MB、启动/每日清理；
- 回读只用原生 `read` + offset/limit；不新增 `cg_read`；
- **验收**：按指针能找回原文；越权/不存在路径有显式错误。

## T4 配置、审计、状态

- 配置默认：`fold.enabled=true`；`minChars=8000`；`headChars=tailChars=1500`；`keepRecent=3`；`ttlDays=7`；`maxMB=256`；`batch.measure=true`；`batch.hiddenAb=internal`。
- 审计字段：`sessionId`、`tool`、`originalChars`、`keptChars`、`omittedChars`、`spillPath`、`savedCharsEstimate`、`status`、`reason`。
- `/cg status`：折叠次数、节省字符估算、spill 占用、跳过原因、失败数。
- **验收**：字段可查；实测/估算不混用；不静默。

## T5 安全与清理

- spill 不进 git、不进记忆索引；文件权限收紧；
- TTL/容量清理；异常退出后下次启动清理；
- 文档说明“spill 可能含敏感内容”；
- **验收**：无残留泄漏；清理可验证。

## T6 批量测量 + 隐藏 A/B

- 只测量：步/回合、调用/步、prompt token、工具构成；
- 内部隐藏 A/B 可开，但默认不改变行为；不承诺收益；
- **验收**：基线 vs 实验报告；不影响正常路径。

## T7 验收场景

- 长 `grep`/`web_fetch`/`browser_content`/`cross_session_read` 输出 → 折叠、回读；
- `pwsh`/`read` 永不折叠；
- tokenGuard 已折结果跳过；
- 最近 N 条不折；
- S4 保护内容不被误折；
- 写 spill/替换失败保留原文；
- M1 的 S4/回注/审计/降级不回退；
- 报告含证据路径与关键数字。
